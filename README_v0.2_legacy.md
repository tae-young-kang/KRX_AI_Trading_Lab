# KRX AI Trading Lab v0.3 — 전체시장 일봉 수집 / 종목 선정 성능 연구

**Windows Python GUI · KOSPI + KOSDAQ · 개인 PC별 독립 DB · 데이터 분석·가상매매 전용**

> ⚠️ 실계좌 및 모의계좌 **매수·매도 주문 API는 아직 구현하지 않았습니다.** 손절·익절은 실제 계좌를 보호하지 않습니다. 키움 API 연동도 계정이 없어 현장 검증되지 않았습니다. 섀도 매매는 스캔 시 관측가에 슬리피지 가정을 적용한 가상 계산일 뿐 실제 주문 호가/시각을 재현하지 않습니다.

## v0.3 핵심 추가사항 (실제 구현)

- **[종목 선정 연구] 탭**: KOSPI·KOSDAQ 48개 사전 정의 조건(거래량비 4단계 × 최소 시가총액 3단계 × 당일 상승률 2단계 × 2시장) 검증. 연구는 가격변동·거래량·거래대금·시가총액 중심이며 아직 AI 머신러닝 모델은 아닙니다.
- **별도 KRX OPEN API 인증키 입력**: [API · 텔레그램] 탭의 `KRX OPEN API Key` 항목. 키움 API 키와 **다른 키**입니다. KRX 측 사용 신청/승인 및 다운로드 서비스 권한 필요. 조회 권한·당일 데이터 제공·요청 한도는 기관 정책에 따릅니다.
- **[KRX 과거 시세 수집]**: 인증 후 KOSPI·KOSDAQ 일봉을 `research.db`에 날짜·종목 단위로 저장; 이미 수집한 거래일은 재요청 방지. 현재 수집 요청 1회 기간은 최대 365일로 제한하며 길게 확보할 땐 기간을 나누어 받아야 합니다. 실제 서비스에서는 HTTP 장애/수집 중단 시 로그 확인 필요.
- **[CSV 불러오기]**: 사용자 실제 일봉 CSV를 `CSV_USER` 소스로 저장. 예제 데이터 `DEMO_research_ohlcv.csv`는 별도로 선택 가능하며 **전부 합성 자료**, 투자 근거로 해석 금지.
- **[48개 조건 검증]**: 과거 70% 날짜를 학습, 이후 30%를 미사용 기간으로 분리. 학습에서만 후보를 정하고 검증 성과는 분리 보고. 종가 이후 신호 → **다음 거래일 시가** 매수 가정, 이후 1·3·5거래일 종가 평가; 3일 기준 왕복비용 0.25%p 가정.
- **추천 평가**: 시장별 일일 Top-K, 시장 종목 동일가중 평균 대비 초과수익, 추천 점수 Spearman Rank IC 및 전략별 추천/수익률 이력. 이는 수익 실현이나 가상계좌 복리 수익률이 아닙니다.
- **연구용 조건 승인/거부**: 기록을 `approved_research`에 저장하되 **실거래 전략 및 주문 설정을 자동 변경하지 않습니다.**
- **자동 조건 연구 옵션**: GUI가 실행 중이고 KRX 키가 있으며 평일 17시 이후에만 최근 시세 수집/조건 평가를 시도합니다. **PC 종료 중에는 아무것도 실행되지 않습니다.**
- **중요한 제한**: 종목별 과거 상장/상폐·수정주가·기업행동 전수 교정, NXT 시가·호가, 실시간 주문 및 체결, 학습/평가 겹침 정교한 purged walk-forward, AI 모델 자동재학습은 아직 구현·검증되지 않았습니다. 연구결과는 실전매수 권고가 아닙니다.

**빠른 체험:** `[종목 선정 연구]` → `합성 예제 가져오기` → `48개 조건 검증` → 전략 행 클릭 → `결과 CSV 내보내기`.

## 설치 및 첫 실행 (Windows)

1. **Python 3.11 이상 설치** (`Add Python to PATH` 체크).
2. ZIP 압축 해제 후 **`run_windows.bat` 더블클릭** (필요 패키지: PySide6, requests, keyring).
3. GUI **[과거 CSV 백테스트]**로 이동하면 **합성 예제 CSV가 자동 선택**됩니다. [조건별 백테스트 실행]을 눌러 14개 실험 결과 및 매매내역 확인.
4. GUI **[종목 스크리너] → [지금 검색]** 시, 기본 **DEMO 합성 종목**을 검색하고 섀도 전략별 다음 관측일 신호를 저장합니다. 같은 날 반복 조회는 실제 다음날 시가 매수가 아닙니다.
5. GUI **[미적용 전략 경쟁]**에서 KOSPI/KOSDAQ×거래량비 기준 (100,120,150,200,300%) 및 초기 기준선 11개의 수익률·일별 손익·가상 거래 조회.
6. **[전략 조건 설정]**에서 직접 필터/손절/익절/갭 상한 조절 후 저장. 새 전략 버전은 별도 가상계좌에 저장돼 과거 결과를 덮지 않습니다.
7. 나중에 키움 API 키 / 텔레그램 토큰을 준비하면 **[API · 텔레그램]** 화면에서 등록. 절대 채팅으로 키를 보내지 마세요.

**예제 파일:** `sample_data/DEMO_synthetic_ohlcv.csv` (약 440행, **실제 시세가 아닌 임의 생성 데이터**).  
**내 데이터로 테스트:** 별도 실제 CSV를 선택하세요. 여기에는 삼성전자 과거 가격을 임의로 주입하지 않았습니다.

커맨드라인 실행/테스트:

```bat
py -m pip install -r requirements.txt
py main.py
py -m pip install pytest
py -m pytest -q
```

Windows EXE 빌드: `build_windows.bat` 실행. `dist\KOSPI_AI_Trading.exe`가 생성됩니다. 현재 ZIP은 **소스코드**이고 사전 빌드된 EXE는 포함하지 않습니다.

### 중요한 거래량 지표 차이

- GUI 실시간 스크리너 `min_vol_ratio`: **키움 ka10030 `pred_rt` 전일 거래량비(%)**. 20일 평균비가 아님.
- CSV 백테스트 `backtest_volume_ratio`: **해당 일 거래량 ÷ 이전 20거래일 평균 거래량 ×100**. 정확히 이전 20거래일을 사용하고 신호는 해당 일 **종가 이후**에만 확정함.
- 두 결과는 **서로 다른 지표**를 사용하므로 두 전략 성과를 동일 실험처럼 비교하면 안 됩니다. 과거 동시간대 누적 거래량/호가 데이터가 없으면 NXT 8시 전략을 백테스트할 수 없습니다.

## 실제 OHLCV CSV 양식

1행에 헤더, 그 아래 종목×일자별 기록이 있어야 합니다. CSV 인코딩 UTF-8/UTF-8 BOM.

```csv
date,code,name,market,open,high,low,close,volume,trade_value_eok,cap_eok
2026-09-01,005930,삼성전자,KOSPI,80000,82000,79500,81000,23000000,18500,4800000
```

**위 한 줄은 형식 설명용 가상 숫자이며 실제 2026년 9월 1일 삼성전자 시세가 아닙니다.**

- `date` YYYY-MM-DD, `code` 종목코드, `market` KOSPI 또는 KOSDAQ, `open/high/low/close` 원화, `volume` 주. 최소 20일+매수/매도일 이상의 과거 행이 필요합니다.
- `cap_eok`: 시가총액 **억원**. 이 값이 빠지고 **시가총액 필터가 ON**이면 종목을 통과시키지 않습니다.
- `trade_value_eok`: 거래대금 **억원**. 누락 시 `(종가×거래량)/1억`으로 근사하며 `candidates.csv`에 출처를 기록합니다. 이 값은 실제 거래대금과 다를 수 있습니다.
- 액면분할·병합·권리락 발생 시 가격/거래량의 일관성 있는 데이터가 필요합니다. 휴장일이 포함되어선 안 되며, 타 종목/시장 간 거래달력 차이는 별도 검증이 필요합니다.
- 최근 20거래일 평균 계산은 과거 20개 봉만 사용; 가격/거래량을 **추가로 내려받지 않습니다**.

## 백테스트 체결 가정과 실패 이유

- 종가로 **신호 확정 → 다음 거래일 시가 매수**. 진입 지연 실험은 신호 이후 **두 번째 거래일 시가**.
- 갭 상승 제한: 다음 진입시가가 신호 종가의 허용폭을 넘으면 **SKIP_GAP**으로 기록(자동 추격매수 없음).
- 익절/손절 도달: 일봉 고가/저가에 닿았다고 가정. 하루에 **두 선 모두 닿으면 손절이 먼저**라고 가정. 갭으로 손절을 뚫으면 **시가**로 가상 청산.
- 위 규칙은 미세한 실제 체결 정보를 모르기 위한 근사이며 실제 지정가 주문 가능성이나 슬리피지를 보장하지 않습니다.
- 현금 부족/최대 보유 초과/기보유/다음 봉 없음 등의 사유를 남김. 종목 선정 성공·진입 실패·매도 결과를 분리해 `backtest_candidates.csv`, `backtest_trades.csv`로 확인.
- 종료 시 남은 포지션은 **미실현 평가**로 자산 곡선에 반영하고 완료된 거래 승률과 구분합니다.
- 가상거래의 수수료, 세금, 슬리피지는 GUI 사용자 설정의 **가정값**입니다. 실제 키움 수수료·거래소별 세율과 다를 수 있습니다.
- **데모 자료에서 높은 수익률이 나오더라도 실전 최적 전략의 근거가 되지 않습니다.** 과거 한 종목/적은 기간에서 얻은 결과를 일반화하지 마세요.

## 저장 위치 및 내보내기

- Windows: `%LOCALAPPDATA%\KOSPI_AI_Trading\`
- `settings.json`: 사용자 조건(비밀번호 제외), `trading.db`: 가상체결, 추천 신호, 조건, 섀도 전략과 일일 자산(재실행 후에도 보존).
- `backtest_history\날짜_시각_고유ID\`: 과거 CSV 실험마다 자동 생성. `backtest_summary.csv`, `backtest_trades.csv`, `backtest_candidates.csv`, `backtest_daily.csv`, `manifest.json`(입력파일명·SHA256·사용된 설정)을 별도 저장.
- GUI의 [미적용 전략 경쟁] 내보내기: `shadow_daily.csv`, `shadow_trades.csv`, `shadow_signals.csv`, `shadow_pending.csv`.
- 키움 App Key, Secret, Telegram Bot Token은 코드와 설정 JSON에 넣지 않고 OS 키링에 저장. 다른 PC에서 실행하면 각자 자기 인증정보를 직접 GUI 입력.
- **프로그램을 종료하면 데이터 수집도 종료됩니다.** 이 버전에서 예약매매/실시간 감시가 지속되는 서버는 없습니다.

## 실전 자동매매까지 남은 작업

1. 키움 NXT 주문 유형 및 거래시장별 동작과 API 응답을 실제 계정으로 확인.
2. 주문/취소/체결 상태, 부분 체결, 미체결 주문, 재접속, 중복 주문·잔고 정합성 처리.
3. 승인된 텔레그램 사용자만 예약주문 허용. 하드리밋·재확인·일일 손실·장애 중지 포함.
4. 보유 종목에 대해 스크리너 순위 API와 무관한 **전용 실시간 체결·호가 감시 및 손절** 처리. 시세가 없으면 체결되었다고 가정하지 않음.
5. 여러 기간의 실제 과거 데이터에서 **시계열 워크포워드/검증**을 수행한 뒤 개선안 승인 과정 강화. 진정한 자동 모델 재학습과 실계좌 주문은 별도 개발·검증 필요.
