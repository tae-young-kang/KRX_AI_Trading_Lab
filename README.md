# KRX AI Trading Lab v0.3 — 종목 추천 성능 연구

> **중요:** 이 프로그램은 현 단계에서 **종목 추천/가상매매/조건 비교용 연구 프로그램**입니다. 실제 키움 계좌 매수·매도 또는 NXT 08:00 손절/익절 주문은 수행하지 않습니다. AI 신경망의 자동 재학습이나 실계좌 수익 보장도 구현되어 있지 않습니다.

## v0.3 새 기능

- **KOSPI / KOSDAQ 전체시장 일별 OHLCV·시총·거래대금 수집**: 별도로 사용 승인받은 **KRX OPEN API**(유가증권/코스닥 일별매매정보) 혹은 사용자가 준비한 CSV. 기존 키움 REST API 키와 **별도** 승인/인증키 필요.
- 48종 조건 실험: 2시장 × 거래량/직전 20거래일 평균 120/150/200/300% × 과거 해당 일 시가총액 1,000/3,000/10,000억원 × 당일 상승률 0/2% 이상, 거래대금 30억원 이상, 20일 MA 상단. **연구용 초기 조건으로, 검증된 최적값 아님.**
- 종가 이후 추천 신호 → **다음 거래일 정규장 시가** 가상진입 → 1/3/5거래일 종가 기준 동일비용 가정하에 수익률 및 **동시장 전체 적격 종목 평균 대비 초과수익**, Rank IC 분석.
- **앞 70% 거래일 학습 / 뒤 30% 별도 기간 평가**, 미래 성과로 추천 점수를 변경하지 않음; 학습 구간 내 예측값도 학습 종료일 너머의 수익률을 사용하지 않음.
- 모든 실험의 일별 추천종목/점수/향후 수익률/추천 조건 버전을 SQLite에 축적. 매번 내보내기 가능. 검증기간 종목별 수익 비율, 평균 초과수익률, Rank IC 표시.
- 조건 **연구 승인/거부** 상태 저장. 승인해도 실전매매나 기존 키움 실시간 스크리너에 연결되지 않음. KRX 거래량/20일 평균과 키움 전일 거래량비는 **서로 다른 지표**이기 때문.
- **KRX 키를 등록한 상태에서 체크박스를 켜면** GUI가 실행되는 평일 17:00 이후 하루 한 번 지난 7일 데이터 수집과 48개 조건 재평가(기존 수집 데이터에 이어붙임). GUI/PC가 꺼져 있으면 실행되지 않으며 빠진 기간은 수동으로 수집해야 함. 실시간 틱 학습 아님.
- 데이터셋은 `KRX` / `CSV_USER` / `DEMO_SYNTHETIC` 3가지로 완전히 분리. 합성 데이터로 산출한 성과는 투자 판단에 사용하지 말 것.

## 설치 · GUI 3분 테스트

1. Windows에 **Python 3.11+** 설치하고 ZIP 압축 해제.
2. `run_windows.bat` 더블클릭 (PySide6·requests·keyring 설치 후 실행).
3. 좌측 **[종목 선정 연구]** → **[합성 예제 가져오기]** → **[48개 조건 검증]**.
4. 표에서 학습구간 초과수익률, 미사용 기간 초과수익률, Rank IC, 표본 수 확인.
5. [결과 CSV 내보내기]에서 `summary.csv`, `signals.csv`, `manifest.json` 확인.
6. 사용자별 SQLite DB는 `%LOCALAPPDATA%\KOSPI_AI_Trading\research.db`에 보존 (기존 `trading.db` 삭제/덮어쓰기 없음).

GUI 미설치 환경에서도 연구 엔진만 확인하려면 `run_research_demo.bat` 실행. 이 방식에는 추가 Python 패키지가 필요하지 않음.

## 실제 과거 데이터 연결

**방법 A — KRX OPEN API (권장):** [KRX OPEN API](https://openapi.krx.co.kr/) 계정 등록, 개인용 API 키 발급, `유가증권 일별매매정보`와 `코스닥 일별매매정보` **각각** 사용신청/승인. 키움과 별도임. GUI [API·텔레그램] 탭의 `KRX OPEN API Key`에 입력 후 보안 저장. [종목 선정 연구] 탭에서 최근 180일 수집부터 시작. 일별 요청을 저장하므로 재요청 시 이미 성공한 날짜는 건너뛰지만, 빈 응답/오류 또는 미승인 시 사용 불가. 수집 범위 최대 365일/회. KRX가 API를 바꾸면 어댑터 수정 필요. **실제 서버/실제 개인 API 키가 없어 라이브 연동 검증은 아직 못 함.**

**방법 B — CSV:** [종목 선정 연구] → [CSV 불러오기]. 필수: `date,code,name,market,open,high,low,close,volume,trade_value_eok,cap_eok`; 마지막 두 필드는 추천에 필요한 값을 제공해야 조건을 통과함(누락 시 임의 보간하지 않음). 날짜별 시가총액/종목 유니버스 포함 권장. 20+5 거래일 이상, 적어도 수십 종목 및 수개월~수년 자료가 있어야 연구 가치가 있음. 주식분할·병합, 상장폐지, 과거 구성종목 포함 여부 주의.

KRX 이용 승인은 기관 약관과 [데이터 재배포 제한](https://openapi.krx.co.kr/contents/OPP/INFO/OPPINFO002.jsp)에 따라야 함. **이 배포 파일은 시장 시세를 포함하지 않음.** 사용자 본인의 인증키/계정으로 사용하며 데이터를 타인에게 재배포하면 안 될 수 있음.

## 추천점수/평가 정의

- 현재 점수는 예측 확률이 아닌 `거래량 상대강도(45) + 거래대금(30) + 당일 등락률 형태(25)`에 의한 **사전 정의 휴리스틱**. 시가총액은 필터 구간으로 사용. 다음 목표는 데이터를 통한 가중치 검증/학습.
- 거래량 급증률 = **당일 전체 거래량 ÷ 직전 20개 거래일 평균 거래량 × 100**. 확정 일봉을 이용하는 장마감 종목선정 모델이며 **장중 동시간대 거래량이나 NXT 08:00 매수가 아님**.
- 추천 후 1·3·5일 수익률 = (추천 다음 거래일 시가 대비 N번째 거래일 종가) - **가정 왕복비용 0.25%p**. 실제 체결·손절·세금은 여기에 포함되지 않음.
- 3일 초과수익률 = 일별 Top-K 추천 평균 **가격수익률** − 동일 시장의 평가 가능 적격 종목 평균 가격수익률. 추천 전략과 기준 모두 같은 왕복 비용을 적용해 차액에서 상쇄됨. KOSPI/코스닥 **지수 대비 초과수익 아님**.
- Rank IC = 각 조건 필터 통과 종목들의 (당일 추천 점수, 미래 3거래일 수익률) Spearman 순위상관, 일별 평균. 데이터 없는 날짜는 제외.
- TRAIN 조건 순위는 **학습 구간의 평균 초과수익률로만 선정**, 뒤쪽 TEST는 **성과 보고용**으로만 사용. 48개 조건을 계속 바꿔 본다면 TEST도 사실상 재사용되는 셈이므로 별도의 미래 실시간 검증이 더 필요.
- 추천일별 평균 수익률은 각 날짜마다 추천이 여러 개이고 기간도 겹쳐 **투자자산 누적 수익률이나 샤프지수가 아님**. 자동매매 시뮬레이터/실제 주문 성과와 엄격하게 분리.
- 표본 수가 작은 실험은 불충분 표시. 비교 기간·기업 행동·휴장·거래정지·체결 가능성에 따른 연구 한계가 있음. KRX 데이터 정책에 따라 정규장 외 시간 체결이 반영되지 않을 수 있음.

## 폴더 및 실행 환경

```
app/krx_history.py    KRX API+CSV 변환 및 source별 SQLite 축적
app/research.py       48개 스크리닝 조건 평가, TRAIN/TEST 분리, Rank IC
app/gui.py            GUI 신규 [종목 선정 연구] 탭 및 KRX Key 입력
research_cli.py       GUI 없이 연구 엔진 실행 가능
sample_data/DEMO_research_ohlcv.csv  완전히 합성된 예제 가격(실제 종목 없음)
tests/test_research_v3.py   출처분리, 미래정보 차단, 승률 평가 등의 자동테스트
```

**실계좌 주문 기능은 v0.3에 없습니다.** 기존 v0.2 가상매매와 CSV 백테스트는 유지됩니다. 사용자별 인증정보는 OS Keyring에서만 보관하며 텍스트 파일/SQLite에 키를 저장하지 않습니다. 실제 데이터를 다른 사람에게 넘기려면 별도 KRX 이용약관 검토가 필요합니다.
