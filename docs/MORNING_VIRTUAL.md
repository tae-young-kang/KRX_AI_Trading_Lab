# 아침 추천 목록의 가상 손익 기록

현재 연결: 목록·설정 고정→공급된 고정 시장의 첫 거래 근거→기존 연습 장부 가상 진입→
익절/손절/설정 보유기간 청산→일별 실현/미실현 기록→`/가상결산` 조회입니다.
별도 매매 엔진을 만들지 않고 기존 `paper_trades`/`paper_exits`/하루 결산을 재사용합니다.
실제 체결 입력과 키움 모의계좌 장부는 이 경로에 합치지 않습니다.
새 공개 목록은 `KRX_OPEN` v2로 전 종목 KRX 시초가를 기준으로 고정합니다. NXT 거래 가능 여부는
별도 정보로 보존합니다. 이 정책은 실제 시장가 주문이나 자동 첫 거래 진입을 실행하지 않습니다.
이미 고정된 v1 목록은 기존 NXT/KRX/미확인 시장과 08:00 마감을 유지하며 바꾸지 않습니다.

## 저장 추천을 텔레그램에서 목록으로 고정하기

1. 일반 추천은 `/추천검색`,테마1은 `/테마1검색`으로 검색을 끝냅니다.
2. `/가상추적 일반 100만원` 또는 `/가상추적 테마1 100만원 익절 2 손절 3`을 보냅니다.
3. 답장의 대상 거래일·저장 추천 기준일·예산·익절/손절·시장 정책을 확인합니다.
4. `/가상추적상태 목록날짜`로 고정한 내용을 다시 봅니다. 결과는 `/가상결산 목록날짜`입니다.

이 명령은 **목록과 설정만 고정**합니다. 첫 거래 자동 수집/가상 진입 예약을 시작하는 명령은 아닙니다.
확인된 KRX 개장 시각 전 거래일이면 그날, 개장 시각 이후나 휴장일이면 다음 XKRX 거래일을 선택합니다.
보통 오전9시가 기준이며 특별 개장일은 거래일 달력의 개장 시각을 사용합니다. 확인 실패 시 추측하지 않습니다.
새 목록을 개장 이후 소급 선정하지 않습니다. 기존 v1의 08:00 고정 마감은 변경하지 않습니다.
일반은 저장된 추천 상위 목록을 그대로 쓰고 원래 검색 조건을 보존합니다.
테마1은 저장된 감지 종목 전체를 씁니다. 빈 최신 결과를 이전 추천으로 대체하지 않습니다.
일반의 익절/손절은 현재 설정,테마1은 기본2%/3%이며 명령으로 바꿀 수 있습니다.
목록 고정 후 다른 예산·정책·추천으로 덮지 않으며,같은 내용 재요청은 같은 기록을 유지합니다.
새 고정은 허용 개인 수신이 활성일 때만 가능하고,수신 중지 후에는 상태 조회만 가능합니다.

NXT 판단은 요청 당시까지 저장된 당일 관측만 사용합니다. 현재 키움 관측 저장 경로는
가능(Y)과 미확인을 구분하며 자격이 미확인이라고 KRX 전용 종목으로 바꾸지 않습니다.
새 목록에서 KRX를 선택하는 것은 사용자 시장 정책이며 NXT 비대상이라고 추정한 것이 아닙니다.
기존 v1의 시장 미확인 종목은 진입 대기를 유지합니다. 첫 거래 피드 연결은 아직 남아 있습니다.

## 기존 가상 보유의 새 가격 확인

`/가상시세갱신` → `/가상시세상태`로 이미 진입한 오늘·이월 가상 보유의 새 가격을 확인합니다.
각 목록의 고정 시장으로 조회하며 기존 v1 NXT 보유를 새 KRX 정책으로 바꾸지 않습니다.
새 가격·날짜·시장 근거가 유효할 때만 기존 가상 손익·익절/손절 계산에 반영합니다.
미진입 목록에 신규 매수를 만들지 않으며 키움 모의계좌나 실제 계좌 주문을 하지 않습니다.
이 수동 조회는 실시간 자동 수신·첫 거래 자동 수집·자동 신규 진입 완료를 뜻하지 않습니다.

## 현재 한계

- 새 KRX 첫 체결 자료의 자동 수집·검증과 자동 진입,
  실제 매수 여부와 자동 대조는 아직 남아 있습니다.20:30에는 저장된 실제 입력과 가상 기록을 구분해 발송합니다. **프로그램만 켜면 매일 자동 추적되는 단계가 아닙니다.**
- 아래 도구는 제공된 계획/거래 근거의 오프라인 재생입니다. `FIRST_TRADE`와 해시는 공급자가 제시한
  근거를 기록하며,파일만으로 거래소 첫 체결이나 장 시작 전 실제로 고정된 추천임을 독립 증명하지 못합니다.
- 일반 조회의 마지막 가격을 시초가로 바꾸지 않습니다. 새 KRX 정책과 기존 v1의 고정 시장을 구분합니다.
- XKRX 라이브러리 달력과 기존 일반 거래 구간 검사를 사용합니다. 임시 거래시간/거래소 자격의 공식 실시간 증명은 아닙니다.
- 날짜별 추천 목록은 별도 가상 계정입니다. 날짜마다 지정 예산을 독립 배분하므로 이월 보유와
  다음날 새 목록의 합계를 하나의 실제 투자 가능 잔액/포트폴리오로 해석하지 않습니다.

## 고정 계획과 거래 근거

`MorningVirtual.prepare`에 모드(`DEMO`/`MOCK`/`REAL_QUOTES`는 **시세 출처**),거래일,
추천 출처 번호,코드/이름/시장/NXT자격 목록,익절·손절·기간·비용 설정,총예산과 고정 시각을 넘깁니다.
가상 실행이며 실제/모의계좌 주문 모드를 켜지 않습니다.
새 공개 생성은 `venue_policy='KRX_OPEN'`을 명시한 v2이며 확인된 KRX 개장 전에 고정합니다.
정책이 없는 저수준 호출·구 재생 입력은 v1 호환으로 기존 08:00 마감을 사용합니다.
고정 후 다른 목록·설정으로 덮지 않습니다.
총예산을 모든 종목에 균등 배분하고,비용·슬리피지를 포함해 소수점 주수를 버립니다.
미확인 시장 종목의 예산도 다른 종목에 재배분하지 않습니다. 한 주 미달은 진입하지 않습니다.

`VenueTrade`는 모드,코드,실제 관측 시장(`NXT`/`KRX`),정수 가격,시간대가 있는 거래·수신 시각,
`FIRST_TRADE`/`TRADE`,근거 SHA256을 받습니다. 같은 모드/시장·해당 거래일·30초 이내 근거만 처리합니다.
신규 v2는 모든 종목에서 KRX 첫 거래 근거만 사용합니다. 기존 v1에 한해 NXT 가능 종목은
NXT 첫 거래, 명시적 비대상은 KRX 첫 거래, 시장 미확인은 대기하는 원래 규칙을 보존합니다.
누락 근거는 대기이며 나중 시세를 진입 가격으로 채우지 않습니다.
같은 진입 요청은 재생해도 중복 매수하지 않고,내용이 다르면 거절합니다.

진입 이후 `TRADE`로 같은 시장의 가격을 관측합니다. 익절·손절은 슬리피지를 반영한
가상 체결가 기준이고,청산 손익에는 고정한 비용 가정을 반영합니다.
보유기간 청산은 기존 설정의 달력 일수입니다. 기준선 가격에 확정 체결된다고 가정하지 않고
도달을 관측한 가격으로 계산하므로 갭/관측 공백과 실제 주문 슬리피지 차이가 있을 수 있습니다.
당일 가격이 없는 이월 보유는 미실현 미확인으로 표시하고 이전 가격으로 0원 성과를 만들지 않습니다.

## 오프라인 재생과 조회

`app.morning_virtual_cli.replay(root,plan,events,now=...)`의 계획 JSON 형식:

```json
{
  "version": 2, "kind": "VIRTUAL_ONLY", "venue_policy": "KRX_OPEN",
  "day": "2026-10-19", "mode": "DEMO", "origin": "example-recommendation",
  "frozen_at": "2026-10-19T08:30:00+09:00", "total_won": 10000,
  "targets": [{"code": "900001", "name": "합성 예제", "market": "KOSPI", "venue": "KRX", "nxt_eligible": true}],
  "settings": {"data_mode": "DEMO", "kiwoom_env": "MOCK", "exit_stop_pct": 3,
    "exit_take_pct": 2, "exit_max_days": 2, "paper_fee_pct": 0.015,
    "paper_sell_tax_pct": 0.2, "paper_slippage_pct": 0.1}
}
```

거래 근거 JSON은 `VenueTrade`와 같은 필드의 객체 목록이며 `at`/`fetched_at`은 ISO 시각 문자열입니다.
미래 근거는 받지 않습니다. 거래 근거는 수신 시각 순서로 제공하고 원본·계좌·키는 저장소에 올리지 않습니다.
구 v1 재생은 예전처럼 입력의 `selection_info`를 무시하며 기존 기록에 새 정보를 주입하지 않습니다.
v2는 해당 정보를 전달·보존합니다. 기존 v1 파일을 v2로 바꾸는 도구가 아닙니다.

```powershell
py -m app.morning_virtual_cli "C:\내폴더\계획.json" "C:\내폴더\거래근거.json"
```

오류 전 유효하게 기록한 진입·청산은 남을 수 있습니다. 같은 근거를 재생해도 중복 거래하지 않습니다.
결과는 `%LOCALAPPDATA%\KOSPI_AI_Trading\morning_virtual\모드\목록날짜.db`에 보관합니다.
업데이트가 반영된 수신기에서 `/가상결산 목록날짜`로 현재 모드의 해당 목록 당일 성과를 읽습니다.
날짜는 목록 기준일이고 모든 날짜/목록을 합친 계좌 전체 손익 조회는 아닙니다.
프로그램 API의 `daily_text(관측일)`은 같은 목록의 이후 날짜도 확인할 수 있습니다.
가상·실제·모의 성과의 통합 비교/누계 화면은 후속 연결 대상입니다.


## 결산 날짜 기준으로 모든 아침 목록 보기

`/가상하루`는 오늘까지의 아침 가상 목록을 날짜순으로 보여줍니다.
과거 날짜는 `/가상하루 2026-10-20`처럼 입력하고 다음 답장의 페이지 명령을 그대로 사용합니다.
당일 목록뿐 아니라 이전 목록의 이월 보유와 당일 매도도 해당 결산일 기준으로 확인합니다.
여섯 종목 이상이면 종목 페이지를 먼저 이어서 보여준 뒤 다음 날짜 목록으로 넘어갑니다.

각 목록은 별도의 가상 예산이므로 목록끼리 계좌 손익/수익률로 합산하지 않습니다.
같은 종목이 여러 목록에 있으면 별개의 가상 진입입니다. 실제 매수 여부와 자동 대조해 제외하는 기능은 아직 남아 있습니다.
당일 가격이 없는 보유는 미확인, 진입이 없는 목록은 손익 미산출로 표시합니다.
현재 모드의 날짜별 가상 DB만 읽으며 실제 체결·키움 모의계좌 기록을 읽거나 주문하지 않습니다.
개별 기록은 읽기 전용으로 확인하지만 여러 DB 전체의 동시 시점 스냅샷은 아닙니다.
20:30 저장 기록 발송은 연결했으며 첫 거래/시세 자동 공급과 실제 송수신 검증은 아직 남아 있습니다.

## 매일 저장 추천 목록 고정하기

`/아침가상예약 일반 100만원` 또는 `/아침가상예약 테마1 100만원 익절 2 손절 3`으로 켭니다.
`/아침가상상태`로 확인하고 `/아침가상중지`로 끕니다. 기본은 꺼짐입니다.
PC와 개인 수신이 켜져 있어야 거래일07:50부터 확인된 KRX 개장 전까지 한 번 시도합니다.
직전 거래일 이후 저장된 일반 추천, 또는 직전 거래일 기준이며 ETF 제외 근거가 있는 테마1이 필요합니다.
새 검색은 하지 않습니다. 일반 추천의 저장 시각만으로 종가 자료의 최신성을 보증하지 않습니다.
일반/테마1 중 하나를 현재 모드에 예약하며 하루 목록을 다른 내용으로 덮어쓰지 않습니다.
KRX 개장 이후 시작·휴장일·오래된 자료는 건너뜁니다. 실패·재시작·발송 미확인 뒤 같은 날 자동 재시도하지 않습니다.
완료가 해당 목록의 마감(새 v2는 KRX 개장, 기존 v1은08:00)을 넘거나 시계가 뒤로 가면 정상 완료로 표시하지 않습니다.
이 예약은 목록·예산·조건 고정만 합니다. 첫 거래 자동 공급/가상 진입/실제 주문은 연결하지 않습니다.

아침 가상 목록은 저장된 추천 전체를 사용하며 종목 수500개 제한을 두지 않습니다.
종목이 많으면 종목당 예산이 작아져1주를 살 수 없는 종목이 생길 수 있습니다.
그때는 해당 종목을 가상 진입 완료로 기록하지 않고,나머지 종목에 예산을 몰아주지도 않습니다.
501개 합성 테마1의 전체 저장/마지막 종목 예산·익절손절·결산은 오프라인으로 검증했습니다.
실제 첫 거래 자동 수집/자동 진입이 연결됐다는 뜻은 아닙니다.

## 고정한 종목을 직접 확인하기

`/가상목록`을 보내면 오늘 목록이 있으면 오늘,없으면 다음 거래일 목록을 보여줍니다.
특정 목록은 `/가상목록 2026-10-20`처럼 날짜를 입력합니다.
다섯 종목씩 보이며 답장 아래의 `다음: /가상목록 날짜 페이지` 명령으로 계속 봅니다.
종목명·코드·코스피/코스닥·고정한 NXT/KRX 시장과 종목당 가상 예산·익절/손절을 표시합니다.
시장 미확인은 KRX로 추측하지 않으며 진입 대기로 표시합니다.
