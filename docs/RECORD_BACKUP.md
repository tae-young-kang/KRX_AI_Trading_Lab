# 거래·추천 기록 백업

연습 기록 화면의 ‘현재 모드 기록 백업하기’를 누르고 저장할 폴더를 고릅니다.
현재 선택된 기록 DB의 SQLite 일관 사본을 새 krx-records-모드-구분값 폴더에 저장합니다.
기존 폴더를 덮지 않으며 완료한 사본은 records.db와 manifest.json 두 파일입니다.

원본의 WAL에 남은 확정 기록도 SQLite backup으로 포함하고, 사본만 단독 DB로 정리합니다.
원본 모드/기록은 바꾸지 않습니다. 사본의 quick_check·필수 기록 테이블·크기·SHA256을
확인한 뒤 새 폴더로 공개합니다. manifest에는 모드/생성시각/크기/해시만 기록합니다.
이 모드는 선택한 파일의 사용 맥락이며 과거 혼합 기록의 출처를 새로 인증하는 값은 아닙니다.

연결 키·settings.json·연구 DB·증권사 접수/체결 DB·텔레그램 수신 기록은 이 백업에 포함하지 않습니다.
따라서 전체 운영 복구용 백업은 아직 아닙니다. 파일에는 거래·추천 기록이 담기므로 개인 저장소에서 관리합니다.
verify_backup은 사본 검증만 하며 복원하거나 현재 기록을 덮지 않습니다.
복원 UI·전체 운영 자료 백업·기기별 복구 검증은 후속 작업입니다.

실제 프로그램/계좌를 실행한 검증은 하지 않았으며 자동 백업이나 외부 업로드 기능도 아닙니다.
