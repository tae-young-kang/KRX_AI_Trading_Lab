# 연습 매도의 일부 수량 기록

이 기능은 앱 내부의 가상 연습 기록입니다. 키움 모의 주문·실계좌 주문·증권사 부분체결이 아닙니다.
선택한 관측 가격과 수수료·세금·미끄러짐 가정으로 일부 수량을 판 것으로 계산합니다.

최초 매수 수량과 당시 조건은 유지하고 남은 수량을 따로 관리합니다. 매수 가격과 매수 수수료의 합은
판 수량 비율로 배분합니다. 마지막 매도에서는 남은 매수 비용을 전부 반영해 비용을 중복 계산하지 않습니다.
매도별 가격·수량·비용 가정·배분 원가·손익을 따로 남기며, 마지막 수량을 판 뒤 전체 진입의 손익을 합칩니다.
최종 매도가 표시는 여러 번의 매도 수량으로 가중한 평균 가정 체결가입니다.

일부 수량을 판 동안에도 원래 진입은 보유 중입니다. 마지막 수량까지 판 뒤에만 한 번의 승·패·본전을 정합니다.
매도 횟수를 늘려 조건별 승률 표본을 늘리지 않습니다. 매도마다 비용 가정이 다르면 각 가정을 보존하며
이를 한 가지 비용 정책의 성과처럼 비교해서는 안 됩니다.

매도 요청 확인 번호는 같은 내용의 재처리를 중복 저장하지 않게 합니다. 같은 번호로 다른 내용을 보내면 거부합니다.
잔량 초과·비정상 수량/가격/비용·이전 매도와 맞지 않는 잔량은 저장하지 않습니다.
잔량 갱신과 매도 이력은 같은 트랜잭션으로 처리해 동시에 요청해도 초과 매도하지 않습니다.

이전 버전의 기록은 보존합니다. 이미 끝난 연습의 손익을 분할매도 이력으로 소급 생성하지 않습니다.
연습 기록에서 ‘선택한 연습 종목 팔기’를 누르면 남은 수량 안에서 팔 수량을 고릅니다.
내용 확인 뒤 가상 매도 기록을 남기며 표에는 남은 수량/처음 수량을 표시합니다.
실현손익은 일부 매도를 포함하지만 완료 거래 수·승률·완료 거래 기대값/손익비는 전량 매도한 진입만 사용합니다.
금액을 확인하지 못한 이전 기록은 본전으로 세지 않고 확인 필요 수를 표시합니다.
조건 성적표는 비용 가정 혼합을 별도 묶음으로 보여주며 개선 후보로 사용하지 않습니다.
매매 CSV에는 처음/남은 수량과 누적 실현손익을 포함하고 ‘나눠 판 내역 CSV’로 각 매도의 비용·배분 원가를
별도로 저장할 수 있습니다. 내부 확인 번호와 요청 원문은 해당 내역 CSV에 넣지 않습니다.
화면 연결은 문법/오프라인 검증 기반이며 실제 GUI 조작/배치 확인은 별도로 남습니다.
실제 시세 모드의 연습 DB도 가상 계산일 뿐 실제 증권계좌의 보유나 체결 기록이 아닙니다.

연습 기록에서 종목 선택 → ‘선택 종목의 매도 내역’을 누르면 매도별 수량, 관측가와 가정 체결가,
배분된 매수 원가, 수수료/세금, 해당 매도 손익과 누적 실현손익을 읽기 전용으로 확인합니다.
내부 요청 번호/원문은 표시하지 않습니다. 매도별 기록이 없는 이전 기록을 추정해 채우지 않습니다.
화면에서 장부 정합성 감사가 완료됐다고 주장하지 않으며 실제 화면 배치 확인은 남아 있습니다.

텔레그램: /연습내역 으로 최근 5개 기록 번호를 보고 /연습내역 번호 로 매도 내역을 봅니다.
매도 1건씩 페이지로 표시하며 다음 명령을 안내합니다. 예: /연습내역 1 2.
수신 시작 시 선택한 모드의 연습 DB만 조회하며 실제 체결 기록이 아닙니다.
기존 허용 사용자 검사를 거칩니다. 중지 후에도 읽기 전용 열람은 가능합니다.
실제 텔레그램 송수신 검증은 남아 있습니다.

연습 기록 전체 목록: /연습내역 목록 2 로 오래된 진입 기록을 5개씩 찾을 수 있습니다.
/연습내역 은 첫 목록, /연습내역 기록번호 는 해당 매도의 상세 기록입니다.
목록 번호와 거래 번호를 구분하며 다른 모드 DB를 섞지 않습니다. 실제 체결 기록이 아닙니다.

## 연습 하루 결산

텔레그램 /연습결산 또는 /연습결산 YYYY-MM-DD 로 현재 모드 DB의 하루 기록을 확인합니다.
매수금액/매수 수수료, 매도금액/매도 수수료/세금, 당일 매도분 비용 차감 손익,
그날 전량 매도를 완료한 거래의 승/패/본전/승률을 따로 표시합니다.
분할매도 손익은 각 매도 날짜에 기록하며 전체 진입 승패는 마지막 매도 날짜에 한 번만 셉니다.
매도별 근거가 없는 이전 완료 기록은 매도금액/손익/승패를 추정하지 않고 제외 건수로 표시합니다.
시간대가 없는 이전 시각은 PC 지역 시각으로 해석한 뒤 한국 날짜로 묶습니다.
이 결산은 앱 안의 연습 자료로 실제 계좌/키움 모의 체결 결산이나 감사 완료가 아닙니다.
익절/손절별 종목 수와 실제 체결 기반 결산·20:30 자동 발송은 아직 미연결입니다.

하루 결산에는 종목/시장별 당일 매수금액·매도금액·실현손익도 표시합니다.
매수·매도금액은 수수료/세금 차감 전, 실현손익은 배분한 매수 비용과 매도 비용 차감 후입니다.
종목 5개씩 표시하며 /연습결산 YYYY-MM-DD 2 로 다음 페이지를 확인합니다.
각 페이지의 전체 결산은 전체 대상 기준이고 아래 종목별 표만 페이지 범위입니다.

PC 연습 기록의 ‘연습 하루 결산 보기’에서 날짜를 입력하면 같은 결산을 읽기 전용 창으로 봅니다.
완료 거래의 마지막 매도 사유(가상 익절/손절/보유기간/기타)를 별도로 셉니다.
이 값은 완료 진입 거래의 기록된 사유 건수이며 중복 없는 종목 수나 실제 체결 근거가 아닙니다.
부분매도의 익절 사유는 완료 거래 수를 늘리지 않고 비용 후 승패와도 별개입니다.
실제 계좌 익절손절별 종목 집계와 20:30 자동 발송은 여전히 후속입니다.

결산 전 매도별 장부가 있는 연습 거래의 수량·매수 원가 배분·가정 체결가·수수료·세금·손익을
재계산하고 잔량/누적 손익·최종 손익률·평균 가격·완료 시각/사유와 대조합니다.
불일치하면 결산 대신 기록 확인을 안내하며 데이터를 자동 수정하지 않습니다.
매도 근거 없는 이전 기록은 새로 만들어 검사하지 않습니다. 이는 내부 산술 정합성 검사로
실제 체결 증명·증권사 비용 대조·외부 손상 전체 감사/복구 완료를 뜻하지 않습니다.

새로 저장하는 장부 시각은 한국 시간대(+09:00)를 명시합니다. 보유기간 청산의 일수는
한국 달력 날짜 차이이며 거래일 수가 아닙니다. 이전 시간대 없는 기록은 기존처럼 PC 지역 시간으로
해석합니다. 다른 지역 PC로 옮긴 오래된 기록의 원래 시간대는 별도 확인이 필요합니다.
