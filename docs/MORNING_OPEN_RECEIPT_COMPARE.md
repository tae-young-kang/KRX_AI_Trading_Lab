# 사용자 첫 거래 원본 CSV ↔ 고정 가상 진입 근거 대조

이 기능은 **실제 증권사/거래소 최초 체결 데이터를 다운로드하지 않습니다**.
사용자가 **별도로 확보한** 일별 첫 거래 주장 기록과 프로그램에 이미 저장된
**v2 KRX_OPEN 가상 진입**을 비교하는 읽기 전용 검사입니다.

## 사용

프로그램의 **연습 거래** 화면에서
**고정 추천·외부 첫 거래 CSV 대조 (읽기 전용)**을 선택해
고정 추천 날짜와 CSV 파일을 지정합니다.

개발자/오프라인 검사 목적의 명령도 지원합니다.

```sh
python -m app.morning_open_receipt_compare --root "<로컬 프로그램 데이터 폴더>" \
  --mode DEMO --day 2026-10-20 --csv "<별도 확보한 CSV 경로>"
```

`root`에는 프로그램의 `morning_virtual/DEMO` 등의 데이터가 있는
**상위 폴더**를 지정합니다. 읽기 전용이며 기존 데이터베이스에 기록하지 않습니다.
`DEMO`, `MOCK`, `REAL_QUOTES` 기록은 교차 사용하지 않습니다.

CSV 헤더는 아래 **8개 열을 정확히** 포함해야 합니다.

```csv
day,market,code,venue,first_at,price_won,evidence_hash,capture_status
2026-10-20,KOSPI,900001,KRX,2026-10-20T09:00:00+09:00,1000,aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa,CLAIMED_COMPLETE
```

**위 종목/가격/해시/시각은 모두 합성 예시이며, 실제 주가나 KRX 원문이 아닙니다.**

- `first_at`: 시간대가 표시된 주장상 첫 거래 시각. 고정 날짜와 일치하고 그 거래일의 KRX 개장 이전일 수 없음
- `price_won`: 주장상 최초 거래 가격, 양의 정수
- `evidence_hash`: 저장된 소프트웨어 근거 기록과 대조할 64자리 소문자 SHA256 형식의 문자열
- `capture_status`: `CLAIMED_COMPLETE` 또는 `UNKNOWN`. 이것은 **사용자가 제출한 수집 완전성 주장일 뿐**, 거래소나 공급자가 서명한 확인서가 아닙니다.
- `market`은 KOSPI/KOSDAQ, `venue`은 KRX만 허용. 동일 시장·종목 중복은 거부
- 1 MB, 최대 1,000행으로 제한. 원본 파일을 앱 밖으로 업로드하거나 자동 저장하지 않음

## 검사 결과

| 상태 | 해석 |
| --- | --- |
| 사용자 제출값 일치 | 사용자 CSV의 날짜·가격·해시가 가상 진입과 일치, 다만 **공식 최초 체결 인증은 아님** |
| 수집 완전성 미확인 | 가격·시각·해시는 일치하나 첫 거래 이전부터 모두 수집됐다는 주장 자체가 없음 |
| 불일치 | 주장상 시초 가격/시각/해시가 가상 진입과 다름 |
| 가상 진입 없음 | CSV에 종목은 있지만 고정 가상 추천에 진입 기록이 없음. 실제 계좌 미매수를 뜻하지 않음 |
| CSV 누락 | 고정 추천 종목에 대한 CSV가 없음. 0% 수익이나 실패 거래로 바꾸지 않음 |

고정 추천 외 종목이 입력된 CSV나 시간이 개장 이전이거나 미래인 데이터는
검사 실패로 처리합니다. 원래 NXT/KRX 혼합 v1 가상 목록은 이 KRX_OPEN 대조에
사용하지 않습니다.

## 보안 및 정확성 한계

**해시가 같거나 `CLAIMED_COMPLETE`이라고 적혀 있어도 신뢰 가능한 원본 출처,
원문 전체 수신 여부, 데이터 공급자 서명, 거래소 최초 체결 인증이 되지 않습니다.**
가상 진입의 `VENUE_FIRST_TRADE`은 소프트웨어 기록 기준일 뿐입니다.

또한 고정 일봉 시가와 실제 시장 첫 체결가, 주문 가격·체결가는 서로 다를 수 있습니다.
이 검사만으로 실제 수익률·승률·진입 시간·미체결/부분체결·체결 가능성을 입증할 수 없습니다.
실제 KRX/키움 API·증권계좌/모의계좌 주문을 호출하지 않고,
CSV/DB 파일을 변경하거나 추천 전략을 자동 변경하지 않습니다.

향후 실제 공급자의 완전성 보장·수신 시각·원문 보존·시간대/시장 정보가
명확한 정식 인터페이스를 확보한 뒤에야 독립적인 출처 인증 단계로 확대할 수 있습니다.
현재의 합성 오프라인 테스트와 Windows GUI 미검증은 실제 연동 성공과 다릅니다.
