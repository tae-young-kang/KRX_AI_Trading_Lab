# 집 PC와 텔레그램으로 사용하기

주 사용 방식은 집 PC에서 프로그램을 켜두고 텔레그램으로 확인하는 것입니다.
PC 화면은 최초 설정과 연결 복구에 사용합니다.

## 실제 매수와 미매수 추천을 구분하기

실제로 산 종목은 체결내역 기준 실제 기록,사지 않은 추천 종목은 가상 성과로 따로 봅니다.
키움 모의계좌 기록도 별도입니다. `/연습결산`은 실제 손익이 아닙니다.
`/실제결산`은 현재 [실제 체결 CSV 입력](ACTUAL_TRADE_RECORDS.md)으로 보관한 내역을 조회합니다.
증권사 자동 대조 전 상태를 표시하며 실제 계좌 주문을 켜지 않습니다.
새 매수 계획과 새 아침 가상 목록은 NXT 가능 여부와 관계없이 KRX 시초가 기준입니다. 실제 매수 정책은 KRX 시초가 시장가이며, 자동 주문·첫 거래 가상 진입은 아직 연결 중입니다. 저장된 실제 입력/가상 기록의20:30 발송 경로는 구현했으며 실제 왕복 검증은 남아 있습니다.
`/가상결산 목록날짜`는 [공급 근거로 기록한 아침 가상 추적](MORNING_VIRTUAL.md)의 해당 목록 당일 성과를 읽습니다.
현재 자동 첫 체결 수집/자동 진입은 미연결이며,조회 명령이 추적·진입을 시작하지 않습니다.
`/아침가상예약 일반 100만원` 또는 `/아침가상예약 테마1 100만원 익절 2 손절 3`으로 매일 저장 추천 목록 고정을 켭니다. 거래일07:50부터 확인된 KRX 개장 시각 전까지 동작합니다. 보통 오전9시 전이며 특별 개장일은 거래일 달력으로 확인합니다. 새 추천 검색이나 매수는 하지 않습니다.
확인: `/아침가상상태` · 끄기: `/아침가상중지`. PC와 개인 수신이 켜져 있어야 합니다.
저장한 목록 고정: `/가상추적 일반 100만원` 또는 `/가상추적 테마1 100만원 익절 2 손절 3`.
대상 거래일과 고정한 내용은 `/가상추적상태`로 확인합니다. 목록 고정이며 자동 진입 시작은 아닙니다.
이미 고정된 이전 목록은 원래 NXT/KRX/미확인 시장과 오전8시 마감을 유지합니다. 새 정책으로 덮지 않으며 NXT 거래 가능 여부와 매수할 시장은 별개입니다.

## 모의 주문 처리 결과 알림

모의 지정가 요청은 `/매수 900001 3주 3000`처럼 주수로 입력하거나
`/매수 900001 1만원 3000`처럼 금액으로 입력할 수 있습니다. 마지막 숫자는
1주당 지정가(원)입니다. 두 번째 예는 10,000원 ÷ 3,000원에서 소수점을 버린 3주입니다.
매도도 같은 형식이며 실제 매도 가능 수량을 다시 확인합니다.
금액은 지정가 기준 주문금액이고 수수료·세금은 별도입니다. 확인 화면에 주수와 남는 금액이 표시됩니다.
한 주문10주·10만원 등 기존 모의 시험 한도는 그대로입니다. 종목명은 오늘 같은 키움 모의 시세에서 확인한 정확한 이름만 지원합니다. 시장가 매수는 아래 별도 요청 형식을 사용합니다. 시초가 예약은 아직 연결되지 않았습니다.

PC에서 당일 모의 주문을 별도로 허용하고 텔레그램에서 내용을 확인한 요청은,
처리 후 같은 개인 대화방에 접수·거절·전송 전 실패·결과 미확인을 자동으로 한 번 안내합니다.
접수 응답은 체결 완료가 아닙니다. 취소 접수도 최종 취소 완료와 구분합니다.
수신이 중지되거나 다른 수신 세션으로 바뀌면 이전 세션의 알림을 발송하지 않습니다.

발송 응답이 없거나 발송 도중 종료됐으면 중복 방지를 위해 자동 재발송하지 않습니다.
`/주문상태`에서 처리 결과와 알림 응답 상태를 확인하고 `/잔고`로 다시 조회하세요.
이 기능은 기존 모의 주문 처리 결과 안내이며 실계좌 주문을 켜지 않습니다.
실제 모의 서버 체결과 Telegram 왕복은 별도 검증이 필요합니다.

새 잔고·체결 조회가 기록과 일치하면 부분체결/전량 체결 수량, 누적 체결금액,
평균 체결가를 추가로 한 번 알려줍니다. 같은 누적 체결 수량은 반복 안내하지 않습니다.
체결 알림은 새 조회가 있어야 갱신되므로 `/잔고`로 확인할 수 있습니다.
알림 시각과 별도로 실제 조회 시각을 표시하며, 비용 차감 전 금액을 실현손익으로 표시하지 않습니다.
현재 이 알림이 익절·손절 매도를 자동으로 실행하는 것은 아닙니다.

## 체결 뒤 익절·손절 조건 감시

`/매수 900001 3주 1000 익절 2 손절 3`처럼 매수 요청에 감시 조건을 붙일 수 있습니다.
내용 확인을 마친 주문에만 적용하며, 조건을 생략한 일반 주문에는 자동으로 붙이지 않습니다.
당일 허용한 모의 연결과 수신이 유지되는 동안 기존 연결 소유 작업자가 새 잔고·체결과 시세를 조회합니다.
30초마다 최대 한 계획을 차례로 확인하므로 여러 계획은 확인 간격이 더 길어집니다.

다른 주문과 섞인 보유, 미체결 잔량, 매도 가능 수량 불일치, 오래된 시세는 판단을 보류합니다.
익절·손절에 도달하면 `/보호상태`에 관측을 저장하고 같은 개인방에 조건 도달 알림을 한 번 시도합니다.
한 번 도달한 계획은 자동 재무장하지 않습니다. 연결이 끊기거나 PC가 꺼지면 감시하지 못합니다.
이 형식은 감시·알림만 허용합니다. 자동 매도는 아래처럼 `자동매도`까지 명시하고 내용을 확인한 새 매수 요청만 가능합니다. 실계좌에는 적용하지 않습니다.

## 추천을 받는 기본 순서

연결 정보를 저장한 뒤 PC 홈에서 `텔레그램으로 추천 받기 시작`을 누르세요.
확인창에서 시작을 선택하고 홈 상태가 `수신 중`으로 바뀌면, 본인이 만든 봇의 개인 대화방에서 `/메뉴`를 새로 보내세요.
연결 설정 화면의 `텔레그램 명령 받기 시작` 버튼도 같은 기능입니다. 홈의 `텔레그램 수신 중지`로 종료할 수 있습니다.
User ID는 내 계정 번호, Chat ID는 봇과 대화할 개인방 번호, Bot Token은 내 봇의 연결 키입니다.
User ID 확인용 봇 대화방에 명령을 보내는 것이 아닙니다. 수신 시작 전에 보낸 메시지는 처리하지 않습니다.
`조건 보기` → 필요하면 `조건 바꾸기` → `새 추천 찾기` → `검색 진행` → `최근 추천` 순서로 사용합니다.
검색 완료 메시지는 종목·가격을 먼저 보여줍니다. 검색 당시 조건과 조회 범위·처리 시간은
메시지에 있는 `/추천상세 검색번호`로 확인하세요. `/추천결과 검색번호`는 간단한 목록으로 돌아옵니다.
조건 바꾸기에서는 시장(코스피/코스닥/둘 다)과 ETF 포함 여부를 버튼으로 고를 수 있습니다.
버튼은 변경안을 만들며, 답장에 있는 `/조건확인 코드`를 2분 안에 보내야 반영됩니다.
한 버튼은 그 항목만 바꾸므로, 적용을 확인한 뒤 다른 항목을 고르세요. 새 변경안은 이전 미확인 변경안을 만료시킵니다.
거래대금 100억원 이상으로 바꾸려면 `/조건변경 거래대금=100 거래대금사용=켜기`를 보내세요.
조건 변경 후에는 새 추천 찾기를 눌러야 새 기준으로 검색합니다. 추천 수는 표시할 최대 개수이며 검색 시장의 종목 수 제한이 아닙니다.
테마1은 별도 발굴 방법이며 `테마1 보기`에서는 저장된 감지 결과를 확인합니다.

테마1 조건은 PC의 `테마1 조건 보기` 또는 텔레그램의 `테마1 조건` 버튼·`/테마1조건`으로 확인하세요.
코스피·코스닥에서 최근 6거래일 중 **거래대금 100억원 이상이면서 전일 종가 대비 당일 고가 +5% 이상**인 날이
3일 이상이면 감지합니다. 휴장일은 제외하고 매 거래일 가장 오래된 날짜를 밀어냅니다.
만족한 날짜는 모두 표시하며 고가 상승률 합계 65% 이상/미만은 분류 표시입니다. 65% 미만도 감지 대상입니다.
일반 추천 조건과 별도이며 `/조건변경`으로 이 기준이 바뀌지는 않습니다.

PC 홈 → `테마1 · 종목 찾기` → `테마1 검색 시작 · 오늘 기준`을 누르세요.
요청 시점의 한국 날짜를 기준으로 최근 6거래일과 전일 종가용 1일을 자동 계산합니다.
주말·휴장일은 직전 거래일까지 사용합니다. 날짜 입력이나 JSON 파일은 필요 없습니다.
달력은 exchange_calendars 4.13.2의 XKRX 자료를 사용하며 공식 실시간 공지가 아닙니다.
지원 범위를 벗어나거나 달력 준비에 실패하면 평일로 추측하지 않고 오류를 표시합니다.
고급 화면의 수동 파일 입력은 과거 연구용으로 남아 있습니다.
시세가 없으면 자료 선택에서 `KRX 수집 후 판정`을 고르세요. 별도의 KRX OPEN API 인증키와
유가증권·코스닥 일별매매정보 서비스 승인이 필요합니다. 내용 확인 후 최근 7거래일의
두 시장 일봉을 최대 14회 요청하고 판정합니다. 확인된 이전 수집 자료는 재사용할 수 있습니다.
오늘 자료는 잠정치이며 다시 조회합니다. 수집 취소·실패 시 일부 일봉은 저장될 수 있으나 새 판정은 만들지 않습니다.
`KRX 저장 자료` 또는 `CSV_USER`를 고르면 저장 시세로만 판정합니다. CSV는 고급 연구에서 먼저 넣으세요.
자료 부족·시장별 날짜 누락도 함께 표시하며 전체 시장 수집 완료를 뜻하지 않습니다.
`자료 부족 · 판정 확인 필요`는 조건에 맞는 종목이 없다는 뜻이 아닙니다. 표시된 날짜의 일봉이 없다는 뜻입니다.
당일 KRX 자료가 아직 제공되지 않았을 수 있으므로 자료 제공 뒤 다시 검색하세요. 날짜를 임의로 과거로 바꾸지 않습니다.
검색 결과는 열린 테마1 창에 자동으로 갱신됩니다. 텔레그램에서는 `/테마1`로 조회합니다.
종목별 알림을 보내려면 PC의 `저장된 최신 테마1 종목을 텔레그램으로 보내기`를 별도로 선택하세요.

PC 판정의 자료 출처는 모드별로 저장됩니다.
텔레그램의 `테마1 새 판정` 또는 `/테마1검색`은 요청한 한국 날짜 기준 거래일을 새로 계산해 저장 시세를 판정합니다.
`테마1 진행` 또는 `/테마1검색상태`로 완료를 확인한 뒤 `/테마1`에서 종목을 보세요.
대기 요청은 2분 안에 시작하지 못하면 만료됩니다. 수신 중지·모드 변경 시 대기 요청을 실행하지 않습니다.
요청 시점의 날짜·출처를 고정하므로 대기 중 PC 설정이 바뀌어도 섞이지 않습니다.
당일 자료는 기본 선택인 `키움 시세로 찾기 · 당일 조회`를 사용하세요. 현재 모드의 키움 연결 키가 필요합니다.
텔레그램 `/테마1검색`도 키움으로 새 시세와 일봉을 조회하고, 완료 안내와 감지 종목별 알림을 보냅니다.
ETF 포함 여부는 고르는 조건에서 설정합니다. 개장 전·주말·휴장일은 직전 거래일까지 계산합니다.
수신 중지 시 남은 발송을 멈추며, 응답 미확인 알림은 자동 재전송하지 않습니다. 주문은 하지 않습니다.
명시적으로 CSV_USER를 선택해 판정한 경우 Telegram은 저장된 CSV 자료를 사용합니다.

## 모드와 선택 연결

모드 설명과 텔레그램 수신 시작 안내는 가상 연습·키움 모의투자·실제 시세를 구분합니다.
화면에 남기는 연습 매매와 텔레그램에서 별도로 확인하는 키움 모의 주문은 다른 기능입니다.
수신 시작은 모의 주문 허용이 아닙니다. 실제 돈 주문은 모든 모드에서 잠겨 있습니다.
새 모의 알림 뒤에는 연결을 유지한 채 `/잔고` → `/잔고결과`로 재조회하세요.
연결 실패·끊김 때만 집 PC에서 연결을 확인합니다.

긴 모의 조회나 주문 확인 중 다른 주문 명령을 보내면 ‘처리 중’이라고 답할 수 있습니다.
그 명령을 나중에 자동 실행하거나 대기열에 넣지 않습니다. `/주문점검`으로 먼저 상태를 확인하세요.
새 전송을 막으려면 `/긴급중지`를 보냅니다. 이미 전송한 주문을 취소하는 명령은 아닙니다.
처리 중 응답을 받은 동일 메시지의 재수신도 새 주문으로 처리하지 않습니다.

## 테마1 검색이 오래 걸릴 때

`/테마1검색상태`는 전체 목록/시세/일봉 등 현재 단계와 조회 진행,검색 경과 시간을 보여줍니다.
남은 시간은 서버 응답·재시도·조회 대상에 따라 달라져 확정하지 않습니다.
`/테마1검색취소`로 대기 중인 요청을 취소하거나 실행 중인 조회의 중단을 요청할 수 있습니다.
실행 중이면 현재 통신 응답/제어 반환 뒤 중단하므로 즉시 멈춘 것으로 표시하지 않습니다.
완료 확인은 `/테마1검색상태`에서 봅니다. 기존 저장 판정은 삭제하지 않습니다.
취소 요청과 저장 완료가 겹치면 이미 저장됐음을 안내합니다. 요청만으로 저장된 결과가 사라졌다고 표시하지 않습니다.
중단한 검색의 검증된 과거 참고 자료는 다음 검색에 사용될 수 있으나 미완성 판정을 발송하지 않습니다.
이 명령은 검색만 다루며 매매 주문 취소 명령이 아닙니다.

## 저장 기록으로 조건 비교를 요청하기

`/조건비교`를 보내면 PC가 저장된 앱 안 가상 거래를 기존 비교 기준으로 분석합니다.
다른 작업 중이면 대기하며2분 안에 시작하지 못하면 만료됩니다. PC와 개인 수신이 켜져 있어야 합니다.
`/조건비교상태`로 확인하고 완료 뒤 `/개선안`에서 변경 후보를 봅니다.
한 페이지에 두 후보씩 표시하며 다음 페이지 명령을 사용합니다. 자세한 앞/뒤 성적은 `/조건성적`에서 봅니다.
분석은 과거에 실제로 가정해 사용한 조건을 비교하며 조건·주문을 자동 적용하지 않습니다.
후보에는 생성 당시 모드와 기본 조건을 남깁니다. 지금 조건과 같다는 보장은 아니며 원격 승인·거부에는 아래 별도 확인 절차가 필요합니다.
확인된 생성 정보가 없는 이전 버전 후보는 원격 목록에서 제외합니다. PC의 기존 기록을 삭제하지는 않습니다.
분석/조회는 시세 수집·실제 체결 조회·주문을 실행하지 않습니다. AI 학습·독립 미래 검증도 아닙니다.
완료 알림의 응답이 불확실하면 자동으로 다시 보내지 않으며 상태/개선안에서 직접 확인합니다.

## 개선안을 PC에서 적용할 때

PC의 개선안 승인 버튼은 생성 당시 기본 조건과 현재 저장 조건이 같은지 확인합니다.
최신 가상 거래 기록이 같은 비교 기준을 계속 만족해야 하며 허용된 추천 필터/가상 익절손절만 바꿀 수 있습니다.
설정을 저장한 뒤 파일에서 다시 읽어 목표 값이 확인돼야 승인 완료로 기록합니다.
저장에 실패하고 기존 값이 확인되면 기존 조건과 검토 대기를 유지합니다.
저장 결과가 불명확하면 미확인으로 남기고 재적용을 차단합니다. 프로그램을 다시 켠 뒤 저장 조건을 확인하세요.
재시작에서는 저장된 값이 이전 값인지 목표 값인지 대조해 승인 기록만 정리합니다. 설정을 자동으로 다시 쓰거나 주문하지 않습니다.
둘 다 아닌 값/손상된 기록이면 미확인으로 남깁니다. 그 경우 자동으로 적용을 반복하지 않습니다.
여러 파일을 하나의 원자적 저장으로 처리한 것은 아니며 적용 과정의 기록과 읽기 대조로 중단을 구분합니다.
이전 버전의 생성 근거 없는 개선안은 새 비교로 다시 만들어야 합니다.
원격 개선안 승인도 아래2분 확인 절차를 거친 뒤 동일한 PC 소유 적용 함수를 사용합니다.

## 텔레그램에서 개선안 승인·거부하기

1. `/개선안`에서 후보 번호와 바꿀 항목을 봅니다. 성적은 `/조건성적`으로 확인합니다.
2. `/개선안승인 1` 또는 `/개선안거부 1`처럼 번호를 입력합니다.
3. 승인 화면의 전체 추천 기준과 가상 익절/손절을 읽고2분 안에 `/개선안확인 코드`를 보냅니다.
4. `/개선안처리상태`로 PC의 저장 대조/거부 결과를 확인합니다. 확인 답장은 적용 완료가 아닙니다.

취소는 `/개선안철회 코드`입니다. `/중지`나 수신 종료는 확인 대기를 철회합니다.
PC가 다른 작업 중이거나 화면에서 조건을 수정 중이면 대기하며,기한이 지나면 적용하지 않습니다.
현재 기준·후보 내용·최신 가상 성적·저장 상태가 확인한 내용과 맞아야 승인합니다.
실제 저장 직전에도 기한과 수신 상태를 다시 확인합니다.
거부는 후보 상태만 바꾸고 조건을 저장하지 않습니다.
적용은 새 일반 추천/가상 매매의 기본값에 대한 것으로 기존 보유·고정 목록·테마1 고정 기준·주문 권한을 바꾸지 않습니다.
AI 학습/독립 미래 검증 완료를 뜻하지 않으며 실제/키움 모의 주문을 실행하지 않습니다.
처리 중 프로그램이 종료되면 요청 상태는 미확인으로 남고 자동 재실행하지 않습니다.
재시작의 저장 대조와 `/개선안`·`/조건`·`/청산조건`에서 실제 저장 결과를 먼저 확인하세요.
기한/권한 상실 뒤 다른 경로에서 파일이 바뀐 경우에는 그 변경을 이 요청의 승인으로 취급하지 않습니다.
그 경우 미확인 기록은 수동 검토 대상이며 자동 승인 복구를 하지 않습니다.

### 개선안의 이후 관측 확인
`/조건비교`로 만든 개선안은 생성 당시 조건을 고정해 별도 가상 관측에 등록해요. `/개선안`에서 새 조회 횟수와 가상 진입·종료 건수를 볼 수 있어요. PC가 새 추천 조회를 해야 관측이 쌓여요. 과거 매매를 새 관측으로 복사하지 않아요.
관측 예산은 가상 100만원, 종목당1주, 최대3종목, 갭상한3%예요. 다음 관측일 조회 가격으로 계산하므로 NXT·KRX 첫 거래나 실제 체결 결과가 아니에요. 기록이 쌓인 것만으로 좋은 조건 검증이 끝난 것은 아니며 조건 승인은 별도 확인이 필요해요.

### 처음 쓰는 메뉴
`/메뉴`에서 추천 검색·진행·결과를 확인하세요. `매매 방법`, `하루 결산`, `가상 추적 방법`, `조건 개선 방법` 버튼은 짧은 사용 순서를 보여줘요. 버튼을 누르는 것만으로 주문하거나 조건을 바꾸지 않아요. `/도움말`은 시작 순서, `/전체명령`은 상세 목록이에요.

### 이미 기록된 가상 보유의 가격 새로 확인하기
`/가상시세갱신`을 보내고 `/가상시세상태`에서 결과를 확인해요. 이미 가상 진입 기록이 있는 보유 종목만 새 가격으로 계산하고, 오늘 목록과 이전 목록을 각각 갱신해요. 기록을 읽지 못했거나 가격이 오래됐으면 미확인으로 안내해요.
이 기능은 신규 매수·계좌 주문을 하지 않아요. 목록 고정만으로 가상 진입이 생기는 것도 아니에요. 자동 첫 거래 진입은 아직 연결 전이에요.

1. `/테마1예약 전체 100만원` 또는 `/테마1예약 종목명 10만원 익절 2 손절 3`을 보냅니다.
2. 다음 KRX 개장일·저장 종가 기준 예상 수량을 읽고 2분 안에 표시된 `/예약확인 코드`를 보냅니다.
3. `/테마1예약목록`과 `/테마1예약상태 번호`로 확인하고 `/예약철회 번호`로 철회합니다.

확정한 요청은 PC를 다시 켜도 조회·철회할 수 있습니다. 확인 전 코드는 재시작하면 만료됩니다.
이 기능은 **미실행 요청 기록**만 남깁니다. 개장 실행·시초가 체결·자동 매도는 아직 연결되지 않았습니다.
예수금을 확보하지 않으며 저장 종가로 계산한 주수는 실제 주문 수량이 아닙니다.
향후 실행 연결 시 새 가격·계좌 상태와 기존 모의 주문 한도를 다시 검사해야 합니다.
실제 시세 보기와 가상 연습 모드에서는 이 실행 요청을 저장하지 않습니다. ETF 제외가 확인된 테마1 판정만 사용합니다.

## 전체 운영 기록을 백업하고 새 폴더로 복구하기

PC 매매 기록 화면에서 **전체 운영 기록 백업**을 누르고 현재 기록 폴더 밖의 저장 위치를 고르세요.
기존 백업 폴더나 그 안쪽은 새 백업·복구의 저장 위치로 선택할 수 없습니다.
내용을 확인하면 프로그램이 종료된 뒤 전체 백업을 만들고 결과와 저장 위치를 알려줍니다.
수신·조회가 종료 중이면 작업을 보류합니다. 종료가 거부된 경우 다시 버튼을 눌러야 하며 나중의 일반 종료에서는 실행하지 않습니다.

**전체 백업 검사**는 선택한 전체 백업의 목록·파일·무결성을 확인합니다. 현재 기록은 바꾸지 않습니다.
**새 폴더로 복구**는 전체 백업과 출력 위치를 고른 뒤 종료하여 새 `krx-restored-...` 폴더를 만듭니다.
현재 기록이나 기존 폴더를 덮지 않고, 복구 폴더가 앱의 활성 데이터로 자동 적용되지 않습니다.

이 백업에는 추천·성과·조건·운영 주문 기록과 미실행 요청이 포함될 수 있으니 개인 자료로 보관하세요.
연결 키·설정·`.env`·개인 CSV는 포함하지 않습니다. 프로그램을 다시 시작하거나 주문 허용을 복원하지 않습니다.
복구 후에도 미실행은 미실행, 미확인은 미확인입니다. 새 수신 시작 시 확인 대기는 만료되며 미확인 주문을 자동 재전송하지 않습니다.
기존 **현재 모드 기록 백업하기**는 한 모드 거래·추천만 저장하는 별도 기능입니다.

## 가상 매매 비용을 텔레그램에서 바꾸기

`/가상비용`으로 현재 모드의 비용 가정을 확인합니다.
예: `/가상비용변경 수수료=0.015 세금=0.2 슬리피지=0.1` → 표시된 `/조건확인 코드`.
2분 안에 확인하면 PC 작업이 끝난 뒤 저장하고 저장값까지 대조합니다. `/가상비용`에서 결과를 확인하세요.
기록: `/가상비용기록` · 되돌리기: `/가상비용복귀 기록번호` 후 다시 확인.

수수료·세금은 0~1%, 슬리피지는 0~3%의 가상 계산 가정입니다. 실제 수수료나 세율을 정해 주는 기능이 아닙니다.
새 매매 조건과 새 아침 가상 목록에 반영하고 과거 고정 목록은 바꾸지 않습니다.
일반 연습의 기존 보유를 나중에 팔 때에는 현재 비용을 적용하는 기존 방식을 유지합니다.
실제/키움 모의 주문, 익절손절, 테마1 기준이나 자동매도 권한은 바뀌지 않습니다.
저장 실패·미확인이면 성공으로 표시하거나 자동 재적용하지 않습니다. 미확인 뒤에는 다른 조건 저장도 차단하고 대기 요청을 취소합니다.
PC를 재시작하면 저장값과 현재 비용·모드·버전을 대조합니다. 대조 후 새 요청만 가능하며 과거 요청은 다시 적용하지 않습니다. 현재 저장값 대조는 과거 미확인 요청의 성공 확정이 아닙니다.
비용 이력은 기록을 시작한 이후만 표시하며, 오래된 청산 이력에 없던 비용을 추측하지 않습니다.

## 시세 수집 · 주문하지 않음

실제 시세 보기 모드에서 오늘 KRX 아침 가상 목록을 먼저 고정하세요.
PC의 **시세 수집 시작** 또는 개인 텔레그램 `/시세수집시작`으로 명시적으로 시작합니다.
확인: **수집 상태** 또는 `/시세수집상태` · 중지: **시세 수집 중지** 또는 `/시세수집중지`.
PC에서 시작한 수집도 현재 허용된 개인 텔레그램의 명시 중지로 끌 수 있습니다. 이전 수신 세션의 종료만으로 새 세션 수집을 취소하지 않습니다.
1~100종목을 지원하며 초과 목록을 조용히 잘라내지 않습니다. 다른 작업 중에는 시작을 기다리며 2분 뒤 만료됩니다.

시세 전용 로그인·0B 등록/수신만 합니다. 계좌 조회·주문·기존 가상 진입이나 손익 변경은 하지 않습니다.
처음 받은 값은 **처음 수신 후보**입니다. 공식 KRX 첫 거래나 정규장 시초가 인증이 아닙니다.
공급 체결시각은 HHmmss이며 날짜는 로컬 수집 세션과 연결한 추정입니다. 9081 원문은 보존하지만 거래소 해석은 미확인입니다.
등록 응답을 받은 로컬 시각은 거래소 등록 효력시각이 아닙니다. 순번·손실복구·서버정렬·서명·완전성은 미확인입니다.

## 추천을 실제로 샀는지 표시하기 · 주문하지 않음

실제 시세 보기 모드에서 `/추천대조`로 고정 추천과 입력한 실제 매수를 확인하세요.
같은 종목이라는 이유만으로 추천 매수로 자동 연결하지 않아요.

- 실제 입력 연결: `/추천매수연결 2026-10-20 900001 체결번호`
- 사지 않았다고 표시: `/추천미구매 2026-10-20 900001`
- 분류를 미확인으로 되돌리기: `/추천분류철회 2026-10-20 900001`

답장의 `/추천분류확인 번호`를 2분 안에 보내야 저장돼요. 새 요청은 이전 확인을 대신하며, 수신 중지·재시작 뒤에는 다시 요청하세요.
실제 연결은 해당 날짜·종목의 정상 BUY 입력이 있어야 해요. 체결번호는 입력 CSV의 fill_id입니다.
`/추천대조 날짜`에서 실제입력 연결 / 미구매 사용자확인 / 미확인을 봅니다.
원본 추천이나 매수 입력이 바뀌면 분류도 확인 실패로 표시하므로 새로 확인하세요.
입력하지 않았다는 이유만으로 미구매로 표시하지 않아요. 분류는 사용자 주장으로서 증권사 검증·미구매 증명이 아닙니다.
이력은 운영 백업에 포함되며 실제·가상 장부와 손익을 바꾸거나 합산하지 않고 주문하지 않아요.

분류를 확인하는 동안 원본 기록이 바뀌지 않도록 잠깐 보호해요. 체결 CSV 입력이 겹치면 잠시 뒤 다시 입력해 주세요.


## 추천 성적을 나눠 보기

`/추천성적분리`를 보내면 한국 날짜로 오늘의 성적을 봅니다. 이전 날짜는 `/추천성적분리 2026-10-20`, 다음 목록은 답장 아래의 다음 명령을 쓰세요.
실제입력 연결 / 미구매 사용자확인 / 미확인으로 나눕니다. 현재 분류 기준이므로 나중에 분류를 바꾸면 과거 조회도 달라질 수 있어요.

미구매라고 확인한 종목만 가상 손익을 계산합니다. 수익률은 **오늘 판 주식의 매수비용(매수 수수료 포함)** 대비 오늘 판 부분의 비용 차감 손익이에요.
분할매도 손익은 판 날에, 승패는 전량 청산일에 셉니다. 열린 보유·미진입·자료 누락은 완료 승률에서 제외해요.
미구매 그룹은 사용자가 고른 일부이며, 그 승률이 전체 추천 전략의 승률은 아닙니다. 목록별 예산도 독립이므로 계좌 전체 수익률로 합치지 않아요.
실제 입력 손익은 `/실제결산`으로 따로 확인합니다. 매수 입력만으로 실제 매도 손익을 추정하지 않아요.
시장 비교 자료가 확인되지 않아 시장초과수익은 미산출입니다. 없는 성과를 0%로 표시하지 않습니다.
이전 시장정책 목록의 성과 분리는 미검증으로 안내하고 기존 가상 조회·다음 목록 명령을 제공합니다.


실제 시세 보기 모드의 새 20:30 결산에는 실제 입력 결산, 전체 가상 기록, 분류별 가상 성적을 나눠 보냅니다.
분류별 성적은 현재 사용자 분류와 목록별 독립 예산 기준이며 실제 손익과 합치지 않아요. 시장 비교 자료가 없으면 초과수익은 미산출입니다.
이미 준비했거나 발송한 오늘의 보고는 업데이트 후에도 바꾸거나 다시 보내지 않아요. 새로 준비하는 결산부터 포함합니다.
조회에 실패하면 내용을 준비하지 못한 상태로 남기며 자동 재시도하지 않아요. `/결산알림상태`로 확인하고 필요하면 `/추천성적분리`로 직접 조회하세요.


## 기간을 나눠 반복검증 · 고급 연구

연구 화면에서 자료 출처를 고르고 **기간을 나눠 반복검증**으로 48개 조건을 비교할 수 있어요. 이전 한 번 학습/검증 방식과 저장 결과도 그대로 남습니다.
시장별 60거래일 학습 뒤 20거래일을 평가하고, 20일씩 옮겨 반복해요. 조건은 매번 학습 기록으로만 고릅니다. 최소 3번의 유효 평가와 충분한 관측이 필요하며 부족하면 후보를 검증 완료로 표시하지 않아요.
표의 최신 학습 후보는 과거 반복평가와 별개입니다. 상세에는 각 기간의 당시 선택과 평가·빠진 가격이 나옵니다.
당일 일봉 종가로 조건을 판단하고 다음 일봉 시가를 연구 진입가로 삼아 1/3/5거래일 종가를 평가해요. 공식 첫 체결 인증이나 장중 익절·손절 체결을 재현한 결과가 아닙니다.
실제자료는 XKRX 거래일과 누락을 대조하고 당일 잠정자료를 제외합니다. KRX의 과거 자료도 재확인 자료가 없거나 평가시점 이후이면 연구를 보류해요. CSV는 사용자 자료이며 출처·기업행동·전체시장이 검증됐다는 뜻이 아닙니다.
비교값은 같은 시장의 자료 있는 종목군 평균이며 KOSPI/KOSDAQ 지수가 아닙니다. 겹치는 보유기간을 독립 표본이나 복리 계좌수익으로 해석하지 마세요.
결과를 다시 열거나 CSV로 내보내면 방법·자료 기준·각 기간을 확인할 수 있어요. 연구 프리셋 승인/거부도 방법별로 따로 기록하며 실제 추천 조건이나 주문을 자동으로 바꾸지 않습니다.
충분한 실제 과거자료로 실행하기 전에는 실제 성과가 미검증입니다. 합성자료 결과도 실제 수익률이 아닙니다.
