# 집 PC와 텔레그램으로 사용하기

주 사용 방식은 집 PC에서 프로그램을 켜두고 텔레그램으로 확인하는 것입니다.
PC 화면은 최초 설정과 연결 복구에 사용합니다.

## 추천을 받는 기본 순서

PC에서 텔레그램 수신을 시작한 뒤, 개인 대화방에서 `/메뉴`를 보내세요.
`조건 보기` → 필요하면 `조건 바꾸기` → `새 추천 찾기` → `검색 진행` → `최근 추천` 순서로 사용합니다.
조건 바꾸기에서는 시장(코스피/코스닥/둘 다)과 ETF 포함 여부를 버튼으로 고를 수 있습니다.
버튼은 변경안을 만들며, 답장에 있는 `/조건확인 코드`를 2분 안에 보내야 반영됩니다.
한 버튼은 그 항목만 바꾸므로, 적용을 확인한 뒤 다른 항목을 고르세요. 새 변경안은 이전 미확인 변경안을 만료시킵니다.
거래대금 100억원 이상으로 바꾸려면 `/조건변경 거래대금=100 거래대금사용=켜기`를 보내세요.
조건 변경 후에는 새 추천 찾기를 눌러야 새 기준으로 검색합니다. 추천 수는 표시할 최대 개수이며 검색 시장의 종목 수 제한이 아닙니다.
테마1은 별도 발굴 방법이며 `테마1 보기`에서는 저장된 감지 결과를 확인합니다.

새 테마1 결과는 PC 홈의 `테마1 · 저장된 감지 종목 보기`를 열고
`새 테마1 판정 만들기 · 저장 시세 사용`을 누르세요. 자료 출처를 고른 뒤 확인한 거래일을
오래된 순서대로 한 줄에 하나씩 입력합니다. 최근 6거래일과 전일 종가용 1일, 최소 7거래일이 필요합니다.
마지막 날짜가 감지 기준일입니다. 휴장일은 빼고 거래일이 빠지지 않았는지 거래소 달력과 대조하세요.
JSON 파일을 만들 필요는 없습니다. 기존 파일 입력 방식도 고급 화면에 남아 있습니다.
시세가 없으면 고급 연구에서 KRX 일봉을 먼저 수집하거나 일봉 CSV를 넣어야 합니다.
이 버튼은 자료를 새로 수집하지 않습니다. 자료 부족·시장별 날짜 누락을 함께 표시하며 전체 시장 수집 완료를 뜻하지 않습니다.
판정 후 창을 닫고 다시 열면 최신 결과를 볼 수 있습니다. 텔레그램에서는 `/테마1`로 조회합니다.
종목별 알림을 보내려면 PC의 `저장된 최신 테마1 종목을 텔레그램으로 보내기`를 별도로 선택하세요.

PC에서 한 번 판정하면 확인한 거래일·자료 출처가 모드별로 저장됩니다.
텔레그램의 `테마1 새 판정` 또는 `/테마1검색`으로 같은 기준일의 저장 시세를 다시 판정할 수 있습니다.
`테마1 진행` 또는 `/테마1검색상태`로 완료를 확인한 뒤 `/테마1`에서 종목을 보세요.
대기 요청은 2분 안에 시작하지 못하면 만료됩니다. 수신 중지·모드 변경 시 대기 요청을 실행하지 않습니다.
요청 시점의 설정을 사용하므로 대기 중 PC 설정이 바뀌어도 섞이지 않습니다.
이 명령은 오늘 날짜로 거래일을 자동 연장하거나 새 시세를 수집하지 않습니다. 새로운 감지 기준일은 PC에서 확인해 주세요.
완료 알림이나 종목별 발송을 자동 실행하는 명령은 아닙니다.

## 모드와 선택 연결

모드 설명과 텔레그램 수신 시작 안내는 가상 연습·키움 모의투자·실제 시세를 구분합니다.
화면에 남기는 연습 매매와 텔레그램에서 별도로 확인하는 키움 모의 주문은 다른 기능입니다.
수신 시작은 모의 주문 허용이 아닙니다. 실제 돈 주문은 모든 모드에서 잠겨 있습니다.
새 모의 알림 뒤에는 연결을 유지한 채 `/잔고` → `/잔고결과`로 재조회하세요.
연결 실패·끊김 때만 집 PC에서 연결을 확인합니다.

긴 모의 조회나 주문 확인 중 다른 주문 명령을 보내면 ‘처리 중’이라고 답할 수 있습니다.
그 명령을 나중에 자동 실행하거나 대기열에 넣지 않습니다. `/주문점검`으로 먼저 상태를 확인하세요.
새 전송을 막으려면 `/긴급중지`를 보냅니다. 이미 전송한 주문을 취소하는 명령은 아닙니다.
처리 중 응답을 받은 동일 메시지의 재수신도 새 주문으로 처리하지 않습니다.

1. PC에서 모드와 텔레그램 허용 사용자·개인 대화를 설정합니다.
2. `텔레그램 명령 받기 시작`을 누릅니다.
3. 모의 알림도 보려면 모의 투자 모드와 모의 전용 키를 저장합니다.
4. PC에서 모의 계좌번호를 입력하고 `1. 모의 계좌 확인`을 누릅니다.
5. 확인 후 2분 안에 `2. 알림 받기 시작`을 누릅니다.

밖에서 끊긴 모의 연결도 복구하려면 4번 전에 `오늘 텔레그램 재연결 허용`을 켜세요.
기본은 꺼져 있으며 파일에 저장하지 않습니다. 켠 경우 복구용 모의 키·계좌를 오늘 이 프로그램의
메모리에 보관합니다. PC에서 알림을 중지하거나 프로그램을 종료하면 지웁니다.
날짜 변경·시계 역행 시 복구 허용은 만료됩니다. 다음 날이나 프로그램 재시작 뒤에는 PC 설정이 필요합니다.

계좌번호와 키는 텔레그램으로 보내지 마세요. 계좌번호는 저장하지 않고 연결 중 메모리에서만 사용합니다.

| 텔레그램 명령 | 할 수 있는 일 |
| --- | --- |
| `/프로그램상태` 또는 `/모의상태` | 프로그램 응답, 모의 연결, 마지막 잔고 확인 시각과 최근 알림 보기 |
| `/모의점검` | 이번 실행의 연결·조회 관측과 남은 모의 검증 항목 보기 |
| `/모의기록` | 재시작 전후의 최근 모의 관측 시각과 연결·조회·처리 이력 보기 |
| `/잔고` | 연결된 키움 모의 계좌의 새 잔고 조회 요청 |
| `/잔고결과` | 조회 진행·완료·실패와 마지막 잔고 확인 |
| `/모의자금` | 최근 30초 조회의 예수금·주문 가능 금액·다음 결제일 예상 예수금 구분 |
| `/모의재연결` | 오늘 허용한 모의 연결이 끊겼을 때 계좌 재확인 후 알림 연결 요청 |
| `/매수`, `/매도` | PC에서 당일 키움 모의 주문을 별도 허용했을 때 모의 주문 내용 확인 |
| `/정정 주문번호 남길잔량 지정가` | 새 조회의 남은 수량 이하로 모의 정정 내용 확인 |
| `/취소 주문번호` | 새 조회의 남은 수량 전부에 대한 모의 취소 내용 확인 |
| `/모의확인 코드`, `/모의철회 코드` | 전송 전 모의 주문 확인 또는 철회 |
| `/주문상태` | 모의 접수 응답·최근 조회 상태 확인 |
| `/주문목록` 또는 `/주문목록 2` | 내 모의 주문 기록을 최근 순으로 5개씩 보기 |
| `/미체결` 또는 `/미체결 2` | 최근 30초 조회에서 내 최신 모의 주문번호와 남은 수량 보기 |
| `/주문점검` | 모의 주문 차단 이유·진행 상태·다음 확인 순서 보기 |
| `/긴급중지` | 키움 모의 새 전송 차단·대기 요청 철회, 재시작 뒤에도 유지 |
| `/모의재개` | 중지 뒤 새 잔고 조회를 확인하고 사용자 긴급중지의 재개안 만들기 |
| `/모의재개확인 코드` | 사용자 긴급중지만 별도로 재개, 기록 충돌 등은 계속 차단 |
| `/조건` | 현재 추천 조건 보기 |
| `/추천기록` 또는 `/추천기록 2` | 현재 모드의 추천 기록을 5개씩, 당시 순위·가격과 보기 |
| `/추천성적` 또는 `/추천성적 2` | 페이지별 1·3·5거래일 가격 관측과 자료 출처 보기(실제 매매 수익률 아님) |
| `/추천요약` | 조건별 가격 관측 수·평균 변화와 자료 부족을 함께 보기 |
| `/조건도움말` | 조건 변경 방법 보기 |
| `/조건변경` | 변경안 만들기: 도움말에 안내된 값을 함께 입력 |
| `/조건확인 코드` | 대기 중인 변경안 승인 |

상태 명령은 마지막으로 확인한 내용을 보여줍니다. 새 증권사 잔고 조회를 실행하지 않습니다.
주문 알림이 오면 잔고를 다시 확인해야 한다고 표시합니다.
모의 알림 연결이 완료되면 `/잔고`로 새 조회를 요청하고 `/잔고결과`로 확인합니다.
조회는 한 번씩 처리하며 요청 간격은 30초입니다. 보유 종목은 코드와 수량으로 최대 15개 표시합니다.
전체 보유 수량과 남은 주문 수량도 표시하며, 주문 가능 금액을 확정할 수 없으면 재확인으로 표시합니다.
연결 중지·조회 실패·인증 변경 시 연결을 다시 확인해야 합니다.
정상 모의 알림 연결이 한 번 확인된 뒤 끊겼고 오늘 원격 복구를 허용했다면 `/모의재연결`을 보냅니다.
`/모의상태`로 결과를 확인하세요. 기존 연결을 닫은 뒤 새 모의 인증·계좌·잔고를 확인하고
알림을 등록합니다. 요청 사이 간격은 30초이며 실패해도 자동 재시도하지 않습니다.
최초 접속 실패·PC에서 직접 중지·복구 허용 만료·연결 정리 실패는 PC에서 다시 설정해야 합니다.

PC와 프로그램이 켜져 있고 인터넷이 연결되어 있어야 답장이 옵니다.
절전·종료 중에는 사용할 수 없습니다. 모의 연결은 자동으로 재접속하지 않습니다.
조회·복구 명령은 주문하지 않습니다. PC에서 별도로 당일 모의 주문을 허용한 경우에만
텔레그램 확인 뒤 모의 매수·매도·정정·취소 전송 경로를 사용합니다. 실계좌 주문은 잠겨 있습니다.
설정과 한도는 [키움 모의 주문 안내](TELEGRAM_KIWOOM_MOCK_ORDERS.md)를 참고하세요.

취소 알림 뒤 `/잔고` → `/잔고결과` → `/주문상태` 순서로 새 조회 대조를 확인할 수 있습니다.
알림과 조회가 같은 연결·주문 계보에 속하는지 확인하며, 최종 취소 완료나 주문 잠금 해제로 판단하지 않습니다.

재시작 운영, 상시 신규 추천 알림은 후속 작업입니다.
현재 검증은 가짜 통신과 임시 자료를 사용한 오프라인 검사이며,
실제 GUI 조작·텔레그램 송수신·키움 모의 접속 검증은 남아 있습니다.

실제 확인 순서와 판단 범위는 [모의 검증 안내](KIWOOM_MOCK_VALIDATION_GUIDE.md)를 참고하세요.
