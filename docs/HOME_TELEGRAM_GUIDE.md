# 집 PC와 텔레그램으로 사용하기

주 사용 방식은 집 PC에서 프로그램을 켜두고 텔레그램으로 확인하는 것입니다.
PC 화면은 최초 설정과 연결 복구에 사용합니다.

1. PC에서 모드와 텔레그램 허용 사용자·개인 대화를 설정합니다.
2. `텔레그램 명령 받기 시작`을 누릅니다.
3. 모의 알림도 보려면 모의 투자 모드와 모의 전용 키를 저장합니다.
4. PC에서 모의 계좌번호를 입력하고 `1. 모의 계좌 확인`을 누릅니다.
5. 확인 후 2분 안에 `2. 알림 받기 시작`을 누릅니다.

밖에서 끊긴 모의 연결도 복구하려면 4번 전에 `오늘 텔레그램 재연결 허용`을 켜세요.
기본은 꺼져 있으며 파일에 저장하지 않습니다. 켠 경우 복구용 모의 키·계좌를 오늘 이 프로그램의
메모리에 보관합니다. PC에서 알림을 중지하거나 프로그램을 종료하면 지웁니다.
날짜 변경·시계 역행 시 복구 허용은 만료됩니다. 다음 날이나 프로그램 재시작 뒤에는 PC 설정이 필요합니다.

계좌번호와 키는 텔레그램으로 보내지 마세요. 계좌번호는 저장하지 않고 연결 중 메모리에서만 사용합니다.

| 텔레그램 명령 | 할 수 있는 일 |
| --- | --- |
| `/프로그램상태` 또는 `/모의상태` | 프로그램 응답, 모의 연결, 마지막 잔고 확인 시각과 최근 알림 보기 |
| `/잔고` | 연결된 키움 모의 계좌의 새 잔고 조회 요청 |
| `/잔고결과` | 조회 진행·완료·실패와 마지막 잔고 확인 |
| `/모의재연결` | 오늘 허용한 모의 연결이 끊겼을 때 계좌 재확인 후 알림 연결 요청 |
| `/조건` | 현재 추천 조건 보기 |
| `/조건도움말` | 조건 변경 방법 보기 |
| `/조건변경` | 변경안 만들기: 도움말에 안내된 값을 함께 입력 |
| `/조건확인 코드` | 대기 중인 변경안 승인 |

상태 명령은 마지막으로 확인한 내용을 보여줍니다. 새 증권사 잔고 조회를 실행하지 않습니다.
주문 알림이 오면 잔고를 다시 확인해야 한다고 표시합니다.
모의 알림 연결이 완료되면 `/잔고`로 새 조회를 요청하고 `/잔고결과`로 확인합니다.
조회는 한 번씩 처리하며 요청 간격은 30초입니다. 보유 종목은 코드와 수량으로 최대 15개 표시합니다.
전체 보유 수량과 남은 주문 수량도 표시하며, 주문 가능 금액을 확정할 수 없으면 재확인으로 표시합니다.
연결 중지·조회 실패·인증 변경 시 연결을 다시 확인해야 합니다.
정상 모의 알림 연결이 한 번 확인된 뒤 끊겼고 오늘 원격 복구를 허용했다면 `/모의재연결`을 보냅니다.
`/모의상태`로 결과를 확인하세요. 기존 연결을 닫은 뒤 새 모의 인증·계좌·잔고를 확인하고
알림을 등록합니다. 요청 사이 간격은 30초이며 실패해도 자동 재시도하지 않습니다.
최초 접속 실패·PC에서 직접 중지·복구 허용 만료·연결 정리 실패는 PC에서 다시 설정해야 합니다.

PC와 프로그램이 켜져 있고 인터넷이 연결되어 있어야 답장이 옵니다.
절전·종료 중에는 사용할 수 없습니다. 모의 연결은 자동으로 재접속하지 않습니다.
이 기능으로 모의 주문이나 실계좌 주문을 실행하지 않습니다.

재시작 운영, 상시 신규 추천 알림은 후속 작업입니다.
현재 검증은 가짜 통신과 임시 자료를 사용한 오프라인 검사이며,
실제 GUI 조작·텔레그램 송수신·키움 모의 접속 검증은 남아 있습니다.
