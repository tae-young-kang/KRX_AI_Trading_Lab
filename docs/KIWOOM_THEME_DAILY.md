# 키움 일봉으로 당일 테마1을 준비하는 경로

`app/kiwoom_daily.py`의 읽기 전용 일봉 어댑터를 `app/theme_kiwoom.py`로 PC/텔레그램 검색에 연결했습니다.
오프라인 경로 검사에 더해 실제 시세 조회로 2026-10-19 기준 56종목 감지·저장과 Telegram 56건의 발송 응답을 확인했습니다.
실제 주문·체결 검증이 아니며 새 기능의 GUI 재실행 및 원격 명령 왕복 검증은 별도로 남아 있습니다.

PC 홈 → 테마1 · 종목 찾기 → 오늘 기준 검색 → 키움 시세로 찾기를 선택합니다.
텔레그램은 `/테마1검색`으로 요청하고 `/테마1검색상태`로 확인합니다. 감지 시 종목별 알림을 보냅니다.
기존 KRX 선택 기록도 텔레그램 새 요청에서는 키움 경로를 사용합니다. 명시적인 CSV 선택은 저장 시세 판정을 유지합니다.
주말·휴장일·개장 전은 직전 세션까지 계산하고, 개장 후의 당일 자료는 관측 당시 값입니다.
ETF는 현재 설정을 따릅니다. 키움 모의와 실제 시세의 일봉 출처는 분리하며 KRX 저장 자료를 덮어쓰지 않습니다.

공식 명세 확인:

- [키움 공식 API 스펙](https://github.com/Kiwoom-Securities/Kiwoom-REST-API/blob/953e5dbff123f437ab4d11a78a95191a685eb51f/kiwoom/_data/kiwoom_api_spec.json)
- 확인 API: ka10081, POST /api/dostk/chart
- KRX 기본 종목코드만 요청합니다. NXT/SOR 접미사를 보내지 않으며 다른 코드의 응답은 거절합니다.
- 수정주가 적용 없이 요청합니다. 기존 KRX 원시 일봉과 같은 개념의 수치를 확보하기 위한 선택이며 기업행동 영향이 해결됐다는 뜻은 아닙니다.
- 거래대금은 백만원에서 억원으로 변환합니다. OHLC의 방향 부호는 절댓값 가격으로 해석합니다.
- 시가총액은 해당 응답에 없으므로 미확인입니다. 당일 근거가 있는 별도 조회를 연결해야 합니다.

요청 날짜가 빠지면 누락 목록을 반환합니다. 이전 날짜로 대체하거나 빈 값을 0으로 만들지 않습니다.
잘못된 가격/순서/중복/연속조회는 오류로 처리합니다. 이 모듈은 저장·발송·계좌 조회·주문을 하지 않습니다.
기존 KiwoomMarket의 인증/조회 제어를 호출자가 제공하며, 검사에서는 가짜 query만 사용했습니다.

빠른 조회:

전체 대상 목록을 먼저 확인한 뒤, 과거5일 자료가 완전하고 충족일이2일 미만인 종목만 일봉 조회에서 제외합니다.
오늘이 추가할 수 있는 충족일은 최대1일이기 때문입니다. 자료가 없는 종목은 제외하지 않습니다.
조회한 후보의7거래일은 모두 키움 일봉을 사용하며 KRX와 날짜별로 섞지 않습니다.
기존 KRX 자료는 조회 계획을 줄이는 데 사용합니다. 원본 정확성/기업행동/전체 시장 독립 검증은 별도입니다.
당일 시가총액은 같은 날짜의 시세 근거가 있을 때만 사용하고, NXT도 감지일 근거가 없으면 미확인입니다.
발송 미확인은 자동 재전송하지 않으며 수신 중지 시 남은 발송을 중지합니다. 주문은 하지 않습니다.

KRX OpenAPI의 빈 응답만으로 공개 시간을 확정하지 않습니다. 오전8시 갱신은 외부 구현체 문서에서 확인한 설명이며,
이번 작업에서 KRX 공식 서비스 명세의 공개 시간까지 확정하지 못했습니다.


## 반복 검색 속도와 과거 자료 재사용

테마1은 ETF를 제외한 전체 종목을 확인합니다. 최초 검색에서는 과거 자료가 부족해 종목별 일봉 조회가 많이 필요합니다.
반복 검색은 같은 시세 서버에서 받은 과거 일봉을 후보 선별에 다시 사용합니다.
이전 5거래일이 모두 확인되고 조건 만족이 2일 미만인 종목만 건너뜁니다.
나머지는 이번 검색에서 최근 7거래일을 다시 조회해 판정합니다. 오늘 거래대금만으로 전체 대상을 줄이지 않습니다.

후보 선별용 자료는 별도 로컬 테이블에 남기며, 이 자료만으로 감지 알림이나 주문을 만들지 않습니다.
모의/실제 시세 서버 자료는 서로 사용하지 않습니다. 과거 날짜에 조회했거나 당일 한국 시각20:00 이후
조회한 스냅샷만 재사용합니다. 시간대가 없거나 미래 시각인 자료는 사용하지 않습니다.
이는 수집 시각에 따른 재사용 정책이며 공식 확정 일봉·기업행동 정정 검증을 보장하지 않습니다.
누락된 날짜가 있으면 해당 종목은 다시 조회합니다. 취소/통신 실패 시 새 판정용 자료·완료된 검색 캐시를 일부만 교체하지 않습니다.
종목별 검증을 마친 과거 일봉은 별도 참고 기록에 남아 다음 후보 선별에 사용할 수 있습니다.

검색 진행에는 전체 종목 수, 과거 조건 미달로 건너뛴 수, 새 일봉 조회 수를 표시합니다.
캐시가 처음이거나 날짜가 바뀌어 필요한 자료가 없으면 다시 조회가 늘 수 있습니다.
실제 단축 시간은 네트워크·대상 수·서버 상태에 따라 달라지며 오프라인 테스트 시간으로 추정하지 않습니다.

### 현재 시세도 후보 선별 뒤에 조회

키움 수집 경로는 전체 코스피/코스닥 목록과 ETF 분류를 먼저 확인한 뒤 과거 자료로 후보를 선별합니다.
그다음 후보의 현재 시세와7거래일 일봉만 조회합니다. 과거 자료가 부족한 종목은 제외하지 않습니다.
일반 추천의 전체 시세 조회와 ETF 선택은 그대로 유지합니다. 후보가0개여도 전체 목록 확인 후 정상적인 빈 판정을 저장합니다.
기존 전체 시세→후보 선별 순서보다 불필요한 시세 요청을 줄이며, 후보별 일봉 조회 자체를 묶음 조회로 바꾼 것은 아닙니다.
최초 검색/자료 부족 때의 긴 일봉 수집과 실제 소요 시간 측정은 후속 과제입니다.

### 검색이 중간에 끊겼을 때

일봉의 날짜·가격·거래대금 검증을 마친 종목은 요청 기준일보다 앞선 과거 자료만 따로 남깁니다.
취소/연결 실패 뒤 다시 검색하면 이 참고 자료로 조건 미달이 확실한 종목을 건너뛸 수 있습니다.
미완료 검색의 당일 자료·판정·알림을 완료한 것처럼 사용하지 않습니다.
자료가 부족하거나 여전히 후보인 종목은 새로 조회하며 모의/실제 시세 서버 자료를 섞지 않습니다.
정상 검색에서 다시 확인한 종목의 중간 참고 기록은 완료 캐시로 대체해 중복 보관을 줄입니다.
이 기능은 중간 조회 손실을 줄이는 기능입니다. 첫 검색 전체 조회나 모든 후보의 일봉 조회 시간을 없애지는 않습니다.
별도 참고 기록이 있어도 새 판정이 끝나기 전에는 감지 알림을 만들지 않습니다.
