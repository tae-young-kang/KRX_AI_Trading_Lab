# 키움 일봉으로 당일 테마1을 준비하는 경로

`app/kiwoom_daily.py`의 읽기 전용 일봉 어댑터를 `app/theme_kiwoom.py`로 PC/텔레그램 검색에 연결했습니다.
실제 API 실행은 별도 미검증이며 가짜 조회·저장·발송으로 전체 경로를 검사했습니다.

PC 홈 → 테마1 · 종목 찾기 → 오늘 기준 검색 → 키움 시세로 찾기를 선택합니다.
텔레그램은 `/테마1검색`으로 요청하고 `/테마1검색상태`로 확인합니다. 감지 시 종목별 알림을 보냅니다.
기존 KRX 선택 기록도 텔레그램 새 요청에서는 키움 경로를 사용합니다. 명시적인 CSV 선택은 저장 시세 판정을 유지합니다.
주말·휴장일·개장 전은 직전 세션까지 계산하고, 개장 후의 당일 자료는 관측 당시 값입니다.
ETF는 현재 설정을 따릅니다. 키움 모의와 실제 시세의 일봉 출처는 분리하며 KRX 저장 자료를 덮어쓰지 않습니다.

공식 명세 확인:

- [키움 공식 API 스펙](https://github.com/Kiwoom-Securities/Kiwoom-REST-API/blob/953e5dbff123f437ab4d11a78a95191a685eb51f/kiwoom/_data/kiwoom_api_spec.json)
- 확인 API: ka10081, POST /api/dostk/chart
- KRX 기본 종목코드만 요청합니다. NXT/SOR 접미사를 보내지 않으며 다른 코드의 응답은 거절합니다.
- 수정주가 적용 없이 요청합니다. 기존 KRX 원시 일봉과 같은 개념의 수치를 확보하기 위한 선택이며 기업행동 영향이 해결됐다는 뜻은 아닙니다.
- 거래대금은 백만원에서 억원으로 변환합니다. OHLC의 방향 부호는 절댓값 가격으로 해석합니다.
- 시가총액은 해당 응답에 없으므로 미확인입니다. 당일 근거가 있는 별도 조회를 연결해야 합니다.

요청 날짜가 빠지면 누락 목록을 반환합니다. 이전 날짜로 대체하거나 빈 값을 0으로 만들지 않습니다.
잘못된 가격/순서/중복/연속조회는 오류로 처리합니다. 이 모듈은 저장·발송·계좌 조회·주문을 하지 않습니다.
기존 KiwoomMarket의 인증/조회 제어를 호출자가 제공하며, 검사에서는 가짜 query만 사용했습니다.

빠른 조회:

전체 대상 목록을 먼저 확인한 뒤, 과거5일 자료가 완전하고 충족일이2일 미만인 종목만 일봉 조회에서 제외합니다.
오늘이 추가할 수 있는 충족일은 최대1일이기 때문입니다. 자료가 없는 종목은 제외하지 않습니다.
조회한 후보의7거래일은 모두 키움 일봉을 사용하며 KRX와 날짜별로 섞지 않습니다.
기존 KRX 자료는 조회 계획을 줄이는 데 사용합니다. 원본 정확성/기업행동/전체 시장 독립 검증은 별도입니다.
당일 시가총액은 같은 날짜의 시세 근거가 있을 때만 사용하고, NXT도 감지일 근거가 없으면 미확인입니다.
발송 미확인은 자동 재전송하지 않으며 수신 중지 시 남은 발송을 중지합니다. 주문은 하지 않습니다.

KRX OpenAPI의 빈 응답만으로 공개 시간을 확정하지 않습니다. 오전8시 갱신은 외부 구현체 문서에서 확인한 설명이며,
이번 작업에서 KRX 공식 서비스 명세의 공개 시간까지 확정하지 못했습니다.
