# KRX 일봉 빈 응답과 기준일자 확인

## 확인한 서비스

[KRX 공식 코스닥 일별매매정보 안내](https://openapi.krx.co.kr/contents/OPP/USES/service/OPPUSES002_S2.cmd?BO_ID=hZjGpkllgCBCWqeTsYFj)를 확인했습니다.
실제 조회는 별도로 저장된 KRX 키를 헤더로 보내며, 승인 API의 `basDd=YYYYMMDD`를 사용합니다.
키움 키·계좌 조회·주문 엔드포인트는 사용하지 않습니다. 키 값은 기록하지 않습니다.

동일 키와 요청 방식으로 양 시장의 과거 자료를 받았습니다. 모든 요청이 인증 또는 경로 오류로 실패하는 상태는 아닙니다.
10/19 빈 응답의 정확한 사유나 공식 공개 시각은 확정하지 못했습니다. 빈 응답을 휴장일·수집 완료로 처리하지 않습니다.
원본 응답과 정규화된 행 수의 차이는 별도 자료 품질 항목이며 전체 종목 검증 완료를 뜻하지 않습니다.

## 응답 날짜 검증

코스피 10/16 실제 응답의 940행에 모두 `BAS_DD=20261016`이 있는 것을 확인했습니다.
실제 API 응답은 모든 행의 `BAS_DD`가 요청한 날짜의 8자리 문자열과 일치해야 합니다.
누락·다른 날짜·잘못된 형식이면 날짜를 임의로 붙여 저장하지 않고 해당 응답 전체를 거절합니다.
검증은 기존 날짜별 저장 트랜잭션 전에 실행되어 기존 일봉과 수집 완료 표시는 보존됩니다.
빈 목록은 계속 빈 목록으로 남으며 다음의 명시적 자료 보완 요청에서 다시 확인할 수 있습니다.

이 변경이 과거에 저장된 모든 캐시의 독립 검증을 완료했다는 뜻은 아닙니다.
키움 일봉과 KRX 일봉은 출처를 분리하고 임의로 같은 날짜의 자료를 섞지 않습니다.
