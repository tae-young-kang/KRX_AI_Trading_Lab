# Windows 설치 준비 확인

처음 사용하는 PC에서는 Python 3.11 이상을 설치하고 프로젝트 폴더를 엽니다.

## 설치만 하기

PowerShell에서 프로젝트 폴더로 이동한 뒤 실행합니다.

```powershell
.\install_windows.bat
```

필요한 패키지를 설치하고 준비 상태를 확인합니다. 프로그램 화면은 열지 않습니다.
Python 실행 명령을 직접 사용할 때는 아래 두 명령을 같은 Python으로 실행하세요.

```powershell
python -m pip install -r requirements.txt
python -m app.environment_check
```

Python 경로를 지정해 실행 중이라면 `python` 대신 같은 실행 파일의 전체 경로를 사용합니다.
점검 실패 답장에는 해당 Python을 사용하는 설치 명령도 표시합니다.

## 점검 결과 읽기

- **확인**: 프로젝트 설치 조건에 맞는 버전이고 모듈 로딩이 됩니다.
- **확인 필요**: 패키지 누락·버전 차이·모듈 로딩 오류 등을 해결한 뒤 다시 점검합니다.
- **보안 보관함 구성**: Windows 저장 구성요소를 만들 수 있다는 뜻입니다. 키를 읽거나 저장하지 않으므로 실제 저장 성공 검사는 별도입니다.
- **거래일 달력**: 현재 날짜 기준 최근7거래일을 준비할 수 있다는 뜻입니다. 거래소 연결·거래 가능 상태를 확인한 것은 아닙니다.

패키지 버전은 프로젝트의 `requirements.txt` 기준으로 확인합니다.
버전 형식을 이해할 수 없으면 확인 필요로 표시합니다.
오류의 원문이나 키·토큰·계좌정보는 출력하지 않습니다.
개인 설정/DB를 읽지 않고 GUI·텔레그램·시세 조회·주문을 시작하지 않습니다.

## 나중에 화면 열기

화면을 열 준비가 됐을 때만 `run_windows.bat`를 실행합니다.
설치 준비 점검에 실패하면 화면을 열지 않습니다.
이번 개발에서는 이 실행 파일과 GUI를 실행하지 않았습니다.

이 설치 명령은 소스 폴더용입니다. 이미 받은 exe 내부는 Python 패키지를 따로 설치해도 바뀌지 않습니다.
exe의 보안 저장 오류는 구성요소가 포함된 빌드로 교체한 뒤 별도로 확인해야 합니다.
