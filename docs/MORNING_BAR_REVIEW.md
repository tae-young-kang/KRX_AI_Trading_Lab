# 고정 추천 일봉 사후 관측 — 체결/수익률과 반드시 분리

## 무엇을 하나요?

매일 아침 고정한 추천 목록의 **당시 종목·KRX 정규장 정책·익절/손절 설정**은 바꾸지 않고,
그 후 저장된 일봉 자료를 읽기 전용으로 대조합니다.
첫 거래 시세가 자동 연결되지 않은 단계에서도 **관측 가능한 자료의 유무와 고가/저가 범위**를
분리해 확인하기 위한 기능이며 주문이나 투자 성과를 만들어내는 기능이 아닙니다.

승인된 개인 텔레그램 채팅에서 아래처럼 입력합니다.

```text
/가상일봉 2026-10-20 2026-10-21 KRX
/가상일봉 2026-10-20 2026-10-21 CSV_USER 2
```

순서대로 **고정 추천 목록 날짜 / 사후 관측 날짜 / 일봉 자료 출처 / 페이지(선택)**입니다.
`DEMO`에서는 `DEMO_SYNTHETIC`만, `MOCK`·`REAL_QUOTES`에서는 `KRX` 또는
`CSV_USER`만 허용합니다. 자료 출처나 현재 시세 모드를 혼합하지 않습니다.
고정일/평가일은 과거의 실제 날짜여야 하고, 평가일이 현재 한국 날짜와 같으면
장중 일봉을 종가로 착각하지 않도록 거절합니다.

### 계산하는 값

- **고정일 일봉 시가**와 사후 관측일의 종가를 비교해 단순 가격 변화율을 계산합니다.
  비용·배당·분할·미체결·보유중 청산은 반영하지 않습니다.
- 고정 당시 익절/손절 퍼센트로 계산한 가격대가 사후 관측일 **고가/저가 범위**에 있는지 확인합니다.
- 같은 날 고가와 저가가 모두 기준에 닿는 경우에는 **익절·손절 동시 도달 가능,
  선후 순서 미확인**이라고 표시합니다. 어느 쪽이 체결됐는지 승패로 판정하지 않습니다.
- 화면 상단은 **가격 참고 가능 X/Y종목 · 자료 누락/무효 N종목 · 익절·손절 동시 범위 M종목**으로
  보유 자료의 범위를 표시합니다. 이는 관측 가능 자료 건수이며 **승률·매매 가능률·체결률이 아닙니다**.
  불가능한 극단 가격으로 계산 값이 무한대가 되는 관측도 미확인으로 분리합니다.
- 고정일 가격, 평가일 가격, 거래량이 부족하거나 종목이 빠지면 **미확인** 상태로 남깁니다.
  0% 수익으로 채우지 않습니다.
- 일봉 범위가 기준에 닿더라도 **실제 주문 체결·거래소 첫 체결·익절/손절 확정은 입증되지 않습니다**.
  특히 다른 거래일에 이미 청산됐을 수 있어 평가일만 보고 손익을 재구성하면 안 됩니다.

### 자료 사용 제한

- **신규 KRX_OPEN (v2) 고정 목록에만 적용**합니다. 기존 NXT/KRX 혼합(v1) 목록의 NXT
  프리마켓 첫 거래와 KRX 일봉 시가를 동일시하지 않습니다.
- `KRX`는 연구 기록에서 다음날 이후 확인/수집된 일봉만 읽는 기존
  `recommendation_bars` 경로를 사용합니다. 저장된 장중 일봉을 자동 보충해 사용하지 않습니다.
  `CSV_USER`는 사용자가 준비한 자료여서 별도 날짜/출처·기업행동 검증이 필요합니다.
- 확인한 수치는 모드별 **아침 추천 고정 목록에 대한 참고자료**입니다. 실제 매수했다는 증거도,
  미매수라는 증거도 아닙니다.
- 현재 실제 매수 내역과는 `/추천대조`, 기존 별도 가상매매 체결/매도 장부와는
  `/가상결산`·`/가상하루`에서 각각 대조합니다.
- 이 명령은 **모의/실제 주문·가상 진입·종목 선택·매매 승인·모든 DB 쓰기**를 수행하지 않습니다.
  검색된 시세도 외부에서 이미 수집/저장되어 있어야 합니다.
- 날짜별 가격 범위만 조회하므로 여러 날의 중간 데이터가 누락됐다면 보유기간 전체 익절/손절
  발생 여부도 알 수 없습니다. 사후 일봉 자료만으로 실현손익·승률을 만들지 않습니다.

## 남은 개발

KRX 공식 첫 체결 근거의 자동 수집·검증, 장중 시세 수집과 실제 가상 진입/익절손절 추적,
사용자 입력 실제 매수분과 가상 미매수분의 안전한 자동 대조, 장중 키움 모의서버 체결 및
Windows GUI/실제 텔레그램 왕복 검증은 이 기능만으로 완성되지 않습니다.

GitHub 오프라인 테스트는 합성 가격·임시 SQLite·가짜 텔레그램 요청으로만 수행합니다.
실계좌 주문 금지와 비밀키 업로드 금지는 그대로 유지합니다.
