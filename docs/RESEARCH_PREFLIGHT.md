# 48개 조건 백테스트 — 외부 대조 자료의 실행 전 품질 확인

## 기능

종목 스크리닝에서 가장 중요한 것은 **추천한 종목의 이후 성과를 신뢰할 수 있는 자료로 평가하는 것**입니다.
잘못 수집된 일봉·불완전한 거래일로 구한 평균 수익률을 전략의 실력으로 착각하지 않도록
기존 외부 시장 데이터 누락 검사와 48개 연구 조건 평가를 연결합니다.

1. 연구 화면에서 연구 자료 출처(`KRX`, `CSV_USER`, `DEMO_SYNTHETIC`)를 선택합니다.
2. **저장 일봉과 외부 거래일·최소 종목 수 대조 (고급)** 버튼에서 외부 CSV를 골라 검사합니다.
3. 검사에 성공하면 **이번 프로그램 실행 중, 해당 자료 출처에 한해** 기준 파일을 기억합니다.
   경고가 있더라도 파일 자체가 올바른 CSV라면 이후 연구에서 품질 경고를 유지합니다.
4. **48개 조건 검증** 버튼을 누르면 동일한 CSV 파일과 현재 저장 DB를 **다시 읽고**
   품질 상태를 평가한 다음 조건 연구를 진행합니다.
5. 품질 평가는 연구 결과 `report['coverage_quality']`에 기록되어 연구 이력의 일부가 됩니다.
   파일의 로컬 경로·내용·인증정보를 보고서에 저장하지 않습니다.

CSV 형식은 [과거 시세 누락 대조 설명](HISTORY_COVERAGE_AUDIT.md)을 참고하세요.
사용자가 독립적으로 검증한 외부 참조 파일이어야 합니다. 앱은 공식 출처를 인증하지 못합니다.

## 상태별 해석

| 연구 보고서 상태 | 의미 |
| --- | --- |
| `NOT_CHECKED` | 별도 참조 자료가 없어 독립 거래일·종목 수 대조를 수행하지 않음 |
| `ALERT` | 참조한 날짜의 자료 누락/종목 수 부족/급감/정규화 제외 또는 저장한 날짜 중 대조되지 않은 날이 있음 |
| `REFERENCE_FLOOR_MET` | **선택된 외부 최소 기준과 대조한 범위에서만** 경고가 없음. KRX 전체 검증 완료는 아님 |

수동 연구는 `ALERT` 상태에서도 탐색 목적의 성과를 계산할 수 있지만,
**품질 경고를 결과에 계속 표시하고 저장합니다.** 해당 결과를 확정된 성과나
실전 매매 전략의 승인 근거로 취급하지 마세요.

GUI에서 켠 자동 KRX 연구는 **선택한 외부 KRX 참조 자료**가 `ALERT`이면
해당 자동 연구 결과를 저장하지 않고 보류합니다. 기존에 별도 참조 파일을
선택하지 않았다면 자동 연구는 `NOT_CHECKED`를 저장하며 실행됩니다.
이는 독립적으로 검증된 성과가 아니라는 뜻입니다.

## 제약과 운영 주의

- 비교할 데이터는 현재 선택한 출처의 DB만 사용합니다. 합성/사용자 CSV/KRX를 섞지 않습니다.
- 외부 참조 파일은 세션 중에만 선택되며 **다른 연구 출처로 바꾸거나 프로그램을 다시 실행하면 선택이 풀립니다.**
  다시 검사하지 않은 새 세션의 보고서는 `NOT_CHECKED`입니다.
- CSV를 지우거나 형식을 바꾸면 다음 연구의 검사 자체가 실패하며, 그 검사에 문제가 있는 상태로
  연구를 계속 저장하지 않습니다.
- 대조에 사용한 종목 수는 **최소 하한**입니다. 하한 충족은 과거 전 상장 종목 포함/휴장/거래 정지/
  상장 폐지/기업행동·수정주가/거래비용·실제 주문 가능성의 증명이 아닙니다.
- 이미 저장된 과거 연구 보고서에는 새 품질 필드가 없을 수 있습니다. GUI는 그런 보고서를
  **외부 대조 기록 없음**으로 안내합니다.
- 이 기능은 연구만 다루며 실계좌 주문 기능·매수 조건 자동 적용·시장 API 인증과 무관합니다.

검증 범위: GitHub Actions Python 3.11, 합성 자료 중심 오프라인 테스트.
Windows PySide6 실제 GUI 클릭, 실제 CSV 출처 확인, KRX 시세 데이터 및 키움 모의 체결 실증은 별도입니다.
