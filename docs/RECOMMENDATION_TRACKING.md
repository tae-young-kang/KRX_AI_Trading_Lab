# 추천 기록과 이후 가격 확인

새 검색에서 실제 화면에 보여줄 상위 N개를 당시 조건·순위·가격·시세/조회 시각과 함께 고정합니다.
생성된 목록은 텔레그램 전송 성공이나 매수·매도 체결 기록이 아닙니다. 과거 검색을 소급 추천으로 만들지 않습니다.
검색한 종목 목록과 추천 계산의 종목/시세 자료가 다르면 저장을 거부해 서로 다른 검색 결과가 섞이지 않게 합니다.
가상 연습·키움 모의 시세·실제 시세의 기록을 나누며 조건을 바꿔도 과거 추천 조건은 유지합니다.

집 PC 홈에서 ‘지난 추천 확인하기’를 누르면 현재 모드의 추천 기록 → 이후 가격 → 조건별 요약을
읽기 전용 탭으로 볼 수 있습니다. 이 창은 자료를 수집하거나 주문하지 않습니다.
추천 기록·이후 가격은 페이지 번호를 바꿔 이전 기록을 5개씩 볼 수 있습니다. 조건별 요약의 범위는 페이지와 별개입니다.
자료가 없으면 아직 평가할 수 없다고 안내하며, 고급 자료 입력은 기본 사용 흐름과 분리합니다.

1·3·5거래일 평가 기반은 명시적으로 확인한 거래일 목록·그 범위·출처와 가격 자료 확인 완료일을 요구합니다.
평일을 거래일로 추정하지 않습니다. 추천한 한국 날짜 다음 거래일부터 셉니다. 종목 가격이 누락된 날짜를
다음 가격으로 건너뛰지 않고 자료 없음으로 남깁니다. 거래일 범위 부족과 아직 도래하지 않은 날짜도 구분합니다.
확인 완료일 뒤 가격은 입력돼 있어도 평가에 쓰지 않으며 다른 종목/시장의 가격으로 채우지 않습니다.

관측 값은 ‘추천 당시 마지막 시세 대비 대상 거래일의 제공된 종가 변화율’입니다.
장중 시세·실제 매수 체결·매도 가능 가격은 서로 다릅니다. 수수료·세금·슬리피지·배당·주식분할 등
기업행동을 반영한 투자 수익률이 아니며 미래 기대수익률이나 승률로 해석하지 않습니다.
사용자 확인 거래일은 공식 거래일 자동 연동과 구분하고, 공식 자료라는 표시는 자료를 넣는 쪽의 근거가 필요합니다.

`/추천기록`은 현재 수신 모드의 추천을 최근 순으로 5개씩 보여줍니다. `/추천기록 2`는 다음 페이지입니다.
`/추천성적` 또는 `/추천성적 2`는 해당 페이지 추천에 저장된 최신 평가의
가격/거래일 출처·확인 완료일·1/3/5거래일 관측을 표시합니다. 평가가 없으면 자료 없음으로 표시합니다.
허용된 개인 사용자만 읽으며 `/중지` 뒤에도 조회할 수 있습니다. 조회 명령은 새 시장 자료를 수집하거나 주문하지 않습니다.
수신 시작 당시 DB/모드에 연결되므로 다른 모드 기록을 섞지 않습니다.
페이지는 1~999999의 정수이며 없는 페이지는 마지막 페이지를 안내합니다. 조회 중 새 검색이 저장되면 페이지 내용도 바뀔 수 있습니다.

`/추천요약`은 전체 저장 이력에서 같은 한국 날짜·조건·종목·시장의 첫 추천을 먼저 선택하고,
그중 최근 3,000개 고유 표본을 세어,
조건·가격 출처·거래일 출처별로 관측 수·상승/하락/동일 가격 수·평균 가격 변화를 보여줍니다.
최근 조건 묶음 3개를 표시하며 좋은 성적순으로 골라 보여주지 않습니다.
자료 누락·아직 미도래·미평가는 손실이나 수익률 0으로 만들지 않고 별도로 셉니다.
관측 20개 미만을 표시하며 20개 이상이어도 종목/기간 중복 때문에 독립 표본이나 미래 수익 증명이 아닙니다.
같은 날 반복 검색으로 원래 첫 추천이 범위 밖으로 밀려 다른 추천으로 바뀌지 않습니다.
다만 최근 고유 표본 3,000개라는 범위는 유지하므로 새 날짜/조건/종목이 늘면 가장 오래된 표본은 제외됩니다.
전체 기간 확정 성적표가 아니며 실제 수익률로 쓰지 않습니다.
이 가격 관측 요약과 비용 후 실제 매매의 승패 성적표는 별개입니다. 자동 조건 변경은 하지 않습니다.

평가 결과는 근거 해시로 중복을 막아 보관하고 자료 수정 시 기존 추천/평가를 덮지 않고 추가합니다.
고급 연구 화면의 ‘저장된 추천의 가격 자료 넣기’에서 아래 JSON 파일을 선택할 수 있습니다.
선택 모드·확인한 거래일 범위 안의 추천을 함께 대조하며 같은 파일을 다시 넣어도 중복 평가를 만들지 않습니다.
전체 파일을 검증한 뒤 한 번에 반영합니다. 입력 파일 원문·파일 경로를 DB에 보관하지 않습니다.
이 기능은 자료 자동 수집이나 공식 검증 기능이 아닙니다. 실제 자료 대조와 실제 송수신 검증은 남아 있습니다.

## 입력 형식 (고급)

다음은 합성 예시이며 실제 주가가 아닙니다. 파일은 UTF-8 JSON, 최대 2MB입니다.
`calendar.days`에는 범위 안에서 확인한 모든 거래일을 오름차순으로 넣고, 확인 완료일은 오늘 이후로 설정하지 않습니다.
각 `prices` 항목은 종목·시장·거래일당 한 개이며 `close`는 확인한 양수 종가입니다.

```json
{
  "version": 1,
  "mode": "DEMO",
  "price_source": "DEMO",
  "calendar": {
    "days": ["2026-10-12", "2026-10-13"],
    "begin": "2026-10-12",
    "end": "2026-10-13",
    "source": "DEMO"
  },
  "available_through": "2026-10-13",
  "prices": [{"day": "2026-10-13", "code": "900001", "market": "KOSPI", "close": 1010}]
}
```

가상 연습은 `DEMO` 모드·가격 출처·거래일 출처만 허용합니다.
키움 모의 시세는 `mode: MOCK`, 실제 시세는 `mode: REAL_QUOTES`를 쓰고,
사용자 제공 가격 출처는 `CSV_USER`, 직접 확인한 거래일 출처는 `USER_CONFIRMED`를 씁니다.
`CSV_USER`는 사용자 제공 자료 구분값이며 여기서 파일 확장자는 JSON입니다.
파일에서 `KRX`/`OFFICIAL`을 지정해 공식 검증 자료로 등록할 수 없습니다.
계좌번호·키 등 추가 필드는 필요하지 않으며 허용 형식 밖 필드는 거부합니다.
거래일 자동 연동·기업행동 조정·비용 반영은 후속입니다.
실제 키움 모의 체결 검증(5단계)이 끝났다는 뜻이 아닙니다.

거래일/완료일/가격 행 날짜는 YYYY-MM-DD 형식만 허용합니다. Python이 해석할 수 있는 압축 날짜나
ISO 주차 날짜라도 저장 키/범위 비교/평가 근거가 달라질 수 있어 입력 전에 거부합니다.
잘못된 날짜 파일은 추천 평가 기록을 쓰기 전에 차단합니다. 테마1도 같은 날짜 검증을 사용합니다.

## KRX 일별 캐시 재조회 기준

KRX 연구 수집은 한국 날짜로 범위를 판단합니다. 당일 응답은 장중/잠정일 수 있어 재실행 시 다시 조회하며,
빈 응답은 휴장일 또는 수집 완료 근거로 저장하지 않습니다. 과거 날짜는 그 날짜가 지난 뒤 받은
시간대 포함 관측·미래가 아닌 시각·응답 행 수와 저장 행 수 일치가 있을 때만 재사용합니다.
시간대 없는 이전 수집 기록은 한 번 재조회해야 합니다. 이는 공식 확정/전체 시장 완전성 판정이 아닙니다.
시장/날짜별 새 응답은 기존 스냅샷을 원자적으로 교체하고 수집 기록도 같은 트랜잭션으로 저장합니다.
날짜/시장/중복 종목이 다른 응답은 거부하며 저장 실패 시 이전 스냅샷과 수집 기록을 유지합니다.
공식 거래일 자료가 아직 없으므로 평일 빈 응답의 반복 요청 가능성은 남습니다.

일별 캐시 쓰기 전 공통 검증으로 날짜·시장·종목 코드·이름·중복과 OHLC 범위·거래량·선택 거래대금/시총을
확인합니다. 비정상 묶음은 일부만 저장하거나 중복을 마지막 값으로 덮지 않고 전체 거부합니다.
검사는 CSV와 KRX 정규화 후 쓰기 경로에 적용됩니다. 원본 응답에서 정규화 제외된 행의 완전성이나
공식 전체 종목 수 대조를 증명하지 않습니다. 수집 출처와 실제 관측 검증은 여전히 별도입니다.

일별 정규화는 실시간 목록/추천 기록과 동일하게 ASCII 영숫자 6자리 단축코드를 보존합니다.
숫자만 허용해 영문 포함 코드가 빠지던 경로를 수정했습니다. ISIN·전각 숫자·잘못된 길이는 변환하지 않습니다.
발행사 단축코드 예시 근거: https://www.hanwhacorp.co.kr/hanwha/investment/basic_information.jsp
수집 기록에는 normalizer_version을 남기며 이전 버전은 요청 범위에 다시 포함될 때 한 번 재조회합니다.
이 변경은 정규화/캐시 범위이며 ETF 별도 엔드포인트·주문 엔진의 코드 지원이나 전체 종목 수집 완료를 증명하지 않습니다.

고급 연구 저장 현황에는 최근 10개 시장/날짜의 수신·정규화·제외 행 수를 표시합니다.
KRX 응답 정규화는 원본 행 수만 함께 전달하고 원문을 관측 장부에 저장하지 않습니다.
제외에는 무거래/유효 OHLC 없음/코드 형식 차이 등이 포함될 수 있으며 이유별 확정 분류는 아닙니다.
단순 행 목록처럼 원본 수신 수를 알 수 없는 입력은 미확인으로 기록합니다.
최신 응답 관측과 현재 보존 캐시 행 수는 다를 수 있습니다. 빈 응답에서 기존 유효 캐시는 보존합니다.
전체 시장 상장 종목 목록과의 독립 대조는 미완료이며 수신=정규화만으로 완료를 주장하지 않습니다.

/추천기록 상단에는 같은 모드의 마지막 검색 시각·그때 조건·추천 개수를 표시합니다.
마지막 검색 결과가 0개이면 이전 검색 종목과 명확히 구분합니다. 이 명령은 저장 기록 조회이며
현재 시세를 새로 검색하지 않습니다. /조건의 현재 설정과 과거 검색 당시 조건은 다를 수 있습니다.
