# 추천 기록과 이후 가격 확인

새 검색에서 실제 화면에 보여줄 상위 N개를 당시 조건·순위·가격·시세/조회 시각과 함께 고정합니다.
생성된 목록은 텔레그램 전송 성공이나 매수·매도 체결 기록이 아닙니다. 과거 검색을 소급 추천으로 만들지 않습니다.
가상 연습·키움 모의 시세·실제 시세의 기록을 나누며 조건을 바꿔도 과거 추천 조건은 유지합니다.

1·3·5거래일 평가 기반은 명시적으로 확인한 거래일 목록·그 범위·출처와 가격 자료 확인 완료일을 요구합니다.
평일을 거래일로 추정하지 않습니다. 추천한 한국 날짜 다음 거래일부터 셉니다. 종목 가격이 누락된 날짜를
다음 가격으로 건너뛰지 않고 자료 없음으로 남깁니다. 거래일 범위 부족과 아직 도래하지 않은 날짜도 구분합니다.
확인 완료일 뒤 가격은 입력돼 있어도 평가에 쓰지 않으며 다른 종목/시장의 가격으로 채우지 않습니다.

관측 값은 ‘추천 당시 마지막 시세 대비 대상 거래일의 제공된 종가 변화율’입니다.
장중 시세·실제 매수 체결·매도 가능 가격은 서로 다릅니다. 수수료·세금·슬리피지·배당·주식분할 등
기업행동을 반영한 투자 수익률이 아니며 미래 기대수익률이나 승률로 해석하지 않습니다.
사용자 확인 거래일은 공식 거래일 자동 연동과 구분하고, 공식 자료라는 표시는 자료를 넣는 쪽의 근거가 필요합니다.

`/추천기록`은 현재 수신 모드의 최근 추천 5개를 보여줍니다. `/추천성적`은 그 추천에 저장된 최신 평가의
가격/거래일 출처·확인 완료일·1/3/5거래일 관측을 표시합니다. 평가가 없으면 자료 없음으로 표시합니다.
허용된 개인 사용자만 읽으며 `/중지` 뒤에도 조회할 수 있습니다. 조회 명령은 새 시장 자료를 수집하거나 주문하지 않습니다.
수신 시작 당시 DB/모드에 연결되므로 다른 모드 기록을 섞지 않습니다.

평가 결과는 근거 해시로 중복을 막아 보관하고 자료 수정 시 기존 추천/평가를 덮지 않고 추가합니다.
현재는 오프라인 저장/평가와 텔레그램 조회 연결 기반입니다. 확인된 거래일/가격 자료를 넣는 사용자 경로·
실제 자료 대조와 실제 송수신 검증은 후속 작업입니다.
실제 키움 모의 체결 검증(5단계)이 끝났다는 뜻이 아닙니다.
