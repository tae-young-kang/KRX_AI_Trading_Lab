# 48개 조건: TEST 기간 초반·후반 성과 안정성 진단

## 왜 추가했나요?

TEST 구간 전체 평균이 플러스라도 처음에는 좋고 마지막에는 성과가 악화된 조건일 수 있습니다.
이를 확인하기 위해 기존 **학습 구간 성과로만 추천 조건을 정렬하는 규칙**은 그대로 두고,
TEST 기간의 **시장 거래일 순서**를 앞·뒤 두 구간으로 나눠 3거래일 시장대비 초과수익을 보여줍니다.

예: TEST에 시장 거래일 20일이 있을 때 **앞 10일 / 뒤 10일**로 나눕니다.
어떤 조건에서 실제로 관측된 초과수익률은 앞쪽 6일, 뒤쪽 4일에만 있다면,
0%로 채우지 않고 앞 6일·뒤 4일의 **관측된 날짜별 동일 가중 평균**을 표시합니다.

입력 값은 기존 연구 엔진이 계산하는 **동일시장 기준일별 3거래일 초과수익률**입니다.
`top_signals.r3`의 **비용 차감 순수익률**과 다르며 서로 섞지 않습니다.

## 표·CSV 표시

연구 화면의 `TEST 초반→후반` 열에 앞/뒤 평균 초과수익을 보여주고,
조건 선택 상세 설명에는 앞/뒤 실제 관측일 수·초과수익 차이 및 주의 문구를 표시합니다.
`summary.csv`에도 아래 컬럼을 추가합니다.

| 필드 | 뜻 |
| --- | --- |
| `test_early_excess3` | TEST 앞 구간의 날짜별 평균 초과수익(%p) |
| `test_late_excess3` | TEST 뒤 구간의 날짜별 평균 초과수익(%p) |
| `test_early_days`, `test_late_days` | 양쪽 구간에서 실제 결과가 관측된 거래일 수 |
| `test_late_gap3` | 뒤 평균에서 앞 평균을 뺀 값(%p) |
| `test_stability_note` | 관측 부족/후반 비양수 전환/감소/증가 등 기술적 설명 |

구간은 **조건마다 실제 추천이 나온 날짜들을 반씩 나누지 않습니다**.
동일 시장의 모든 조건이 같은 TEST 시장 거래일 분할을 사용하므로,
관측이 많은 조건에 유리하게 경계를 임의 변경하지 않습니다.
5일 미만씩만 관측된 경우 표본 부족을 명시합니다. 5일은 단순한 안내 기준입니다.

## 안정성으로 무엇을 판단하면 안 되나요?

- TEST 초반·후반은 **하나의 기존 TEST 기간을 재사용한 진단**이며 새로운 독립 검증 구간이 아닙니다.
- 여러 종목/날짜의 성과는 공통 시장 충격과 3거래일 보유 기간 중첩의 영향을 받습니다.
- 마지막 TEST 날들은 아직 3거래일이 지나지 않아 관측에서 제외될 수 있습니다.
- 연구 시세에 없는 **시장 전체 누락일은 내부 합집합으로 검출할 수 없습니다**.
  독립 검증을 위한 거래일·종목 수 감사(`docs/HISTORY_COVERAGE_AUDIT.md`)도 별도 필요합니다.
- 상장폐지/기업행동/수정주가/생존편향/비용과 체결 가능 가격은 이 진단만으로 검증되지 않습니다.
- TEST 후반 결과가 좋은 조건을 TEST 숫자로 **재정렬·자동 채택하면 검증 기간에 과적합**할 수 있습니다.
  구현은 기존 TRAIN 순서 및 `chosen_on_train_only`를 절대 변경하지 않습니다.
- 외부 데이터 품질이 `NOT_CHECKED`/오류 상태인 결과도 독립 검증 완료로 간주할 수 없습니다.

이 기능은 온라인·실계좌/모의계좌 주문을 실행하지 않습니다. 실제 Windows GUI 사용,
KRX 공식 독립 데이터, 실제 키움 모의 주문/HTS 대조는 별도 실증이 필요합니다.
