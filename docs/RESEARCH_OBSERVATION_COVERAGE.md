# 연구 추천의 3거래일 가격 확보 상태

평균 성과가 일부 추천 종목의 가격만으로 계산됐는지 확인하도록, 조건별 TRAIN/TEST에
추천 가격 확보 집계를 추가합니다. 기존 평균·조건 순위·TRAIN-only 후보는 바꾸지 않습니다.

`summary.csv`의 `train_r3_*`, `test_r3_*` 필드:

- `selected`: 생성한 전체 추천 수. 같은 종목도 추천 날짜가 다르면 별도 기록입니다.
- `observed`: 기존 signals의 3거래일 결과가 관측된 추천 수. 0%도 관측으로 셉니다.
- `missing`: 자료 내 목표 시장 거래일이 있지만 추천의 결과가 없는 수.
- `embargo`: TRAIN의 목표일이 학습 마감 경계를 넘어 평가에서 제외된 수.
- `tail`: 자료 끝까지 목표 3번째 시장 거래일이 확보되지 않은 TEST 추천 수.
- `complete_days`, `partial_days`, `missing_days`: 목표일이 확보된 추천일에서 모든 추천/일부/전부 누락한 날짜 수.

`selected = observed + missing + embargo + tail`입니다. 학습 경계 제외와 자료 끝쪽은
가격 누락이나 0% 수익으로 대체하지 않습니다. 선택 조건 상세 화면에 TEST 집계를 표시합니다.
이전 보고서에는 집계 기록 없음으로 안내합니다.

이 집계는 **signals의 3거래일 가격 확보 상태**입니다. 기존 TRAIN 성과 요약은
5거래일 경계도 함께 제한하므로 `train_signals`와 `train_r3_observed`가 다를 수 있습니다.
기존 평균을 완전 관측일만으로 다시 계산하거나 자동 승인/주문하지 않습니다.

시장 거래일은 현재 입력의 같은 시장 날짜 합집합입니다. 시장 전체 누락일·공식 달력·
기업행동·거래 가능성·독립적인 실제 수익 검증을 증명하지 않습니다.
